Nook 0.1.24 预览版 · 滚动截屏与更新入口

版本标签：v0.1.24-preview，以 GitHub 发布页实际资产为准。

本版改进
- 滚动截屏采用固定、可拖动位置的实时预览面板；长图按宽度显示，可滚动查看。
- 停止滚动后补取尾帧；“完成”整理末屏并进入编辑，“取消”或一次 Esc 结束整次截图。
- 普通截图也统一为一次 Esc 退出；直接拖动四边 / 四角调整选区，无需切换工具。
- 图片预览与独立看图右键新增“复制图片”，支持 Ctrl+C。GIF 复制当前静帧；增强格式按实际解码尺寸复制。
- 新增“设置 → 关于与更新”：主动检查 GitHub、选择预览版本、校验下载并确认重启；正常保存退出、元数据备份和新版启动确认后完成更新，保留旧版和原素材。
- 浏览器插件仍为 0.2.21，正常连接时无需替换；已有图库、项目、贴图及预览功能沿用。

安装 / 升级
1. Windows 10/11 x64：下载 Nook-Setup.exe，并按 SHA256SUMS.txt 核对文件；Source code 不是安装包。
2. 先完整备份图库、画布与贴图，保存编辑，再从“更多 / 托盘 → 退出 Nook”完全退出；右上角 × 通常只收进托盘。
3. 手动运行安装包。0.1.23 及更早版本没有主程序更新入口，首次必须这样升级；本版之后可到“设置 → 关于与更新”检查。
4. 或完整解压 Nook-0.1.24.0-portable.zip 后运行 Mori.exe，不要只复制 EXE。便携版默认仍使用用户数据目录。
5. 新电脑首次空图库是正常的；程序包不含个人素材、设置或配对密钥。迁移见 Nook-Guide.txt，不要把旧电脑配对文件直接覆盖过去。

验收与限制
本轮仅后台验证，未完成真实滚动网页、Esc 系统路由、混合 DPI 双屏或真实安装 / 回退验收。按用户要求，不在本机操作测试窗口或安装新版；不承诺每台电脑和网页均可用。
滚动选区限单屏。请缓慢同向滚动，相邻画面保留重叠，避开动画、视频和变化的悬浮区域，并核对预览；补取尾帧不等于任何页面都不会漏采。
更新的元数据快照不含全部素材、画布附件或贴图原图，不替代完整备份。安装包未商业代码签名，请核对来源与 SHA-256，不要关闭系统安全防护。
