# R3 画布保存与重开结构补测

本目录保留实际审查包 `AAD2676D…` 的原样测试源码。主程序固定为 `97B122310B1033BE7EBDA63730F929C256D8D0972CBC3497C7A7D6539CCA50D6`，不属于默认产品构建，不修改生产画布。

原任务 913 在重开两张图片后比较 `JSON.stringify` 原始字符串失败。`original/` 保留原助手；新助手继续保留旧比较的结果，另记录前后原始 JSON、完整 shape 记录及规范化 JSON。结构比较只忽略对象键顺序；数组顺序、属性、标量类型、数值均严格一致，不采用容差。七项比较器自检先在虚拟机运行，随后执行实际导入、保存、关闭、重开、资源解码与原字节检查。原失败不会因补测而改写。

`source-provenance.json` 记录实际被审查源码、引用及原输出哈希。`reviewed-payload-manifest.json` 是实际运行包的清单，含 176 个未变产品依赖与两个助手文件；重编译后不能沿用原助手输出哈希。实际运行结果以仓库的 [0.1.45 验证记录](../../../docs/Nook0.1.45验证记录.md) 为准。

用 Python 3.11 或更新版本执行：

```powershell
python build.py --build <冻结R3构建目录> --output <不存在的新输出目录>
```

脚本核对源码、R3 主程序及所有编译引用，只编译，不运行测试或产品。输出应重新封装到独立、按哈希命名的 VM 包，更新清单中的助手源码/程序哈希，保留其余产品依赖的精确哈希，再由单一虚拟机控制器执行 `CanvasWebJourneyGuest.exe --run`。助手本身要求专用 QEMU / NookTester、独立数据目录和受控进程树，禁止在实体机运行。不要用新编译程序覆盖已执行包，也不要将编译成功当作测试通过。
