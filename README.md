# Nook · 0.1.30 预览版

Windows 10/11 x64 的本地工具集合：素材收藏、图片与文档预览、截图翻译、项目画布、贴图、3D 查看和格式转换。

**[下载安装包](https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.30-preview)** · [使用说明](docs/使用说明.md) · [本版变化与验证范围](docs/Nook0.1.30发布说明.txt)

主程序及安装器 **0.1.30.0**，随附浏览器插件 **0.2.27**。发布页中的 `Nook-Setup.exe` 是安装包；`Source code` 是开发源码。公开下载不需要 GitHub 账号。

## 安装和更新

1. 下载并运行 `Nook-Setup.exe`。已有 Nook 时，先保存编辑内容并从「更多 → 退出 Nook」正常退出；右上角 × 可能只是收进托盘。
2. 安装后使用桌面或开始菜单中的 Nook。安装器保留图库、设置、贴图、画布及已经选择的保存路径，不把 D 盘图库重新变成 C 盘空图库。
3. 后续可在「设置 → 关于与更新」主动检查；本版为预览版，需要允许预览版本。下载后检查大小与 SHA-256，再由你确认重启更新。

更新采用固定启动入口，内部先准备并验证新程序，正常保存退出后切换。新主窗口确认启动成功后，清理已核对身份的旧程序文件；不因同名目录就删除内容。失败时保留旧程序及恢复入口。旧目录混有素材、未知文件、正在使用的程序或校验不符时会保留并提示，不承诺删除所有历史文件。备份不等于完整素材副本。

便携版下载 `Nook-0.1.30.0-portable.zip` 后完整解压，运行 `Mori.exe`。兼容文件名沿用 Mori，不是另一套软件；不要只复制单个 EXE。便携版采用手动更新。已安装同版本本地候选的电脑，也请手动安装本次发布包。

环境：Windows 10/11 x64、.NET Framework 4.8；画布、3D 和部分视频使用 WebView2，OCR 组件可能需要 Visual C++ x64 运行库和相应语言包。安装包尚未商业代码签名。

## 日常使用

- **素材库**：拖入图片或文件，分类、搜索、多选整理；本地快捷收藏保留原文件地址。文件夹快捷方式留在本地收藏，避免当成图片素材混入全部素材。
- **图片和文件预览**：打开图片、视频、PDF、文本及支持的设计文件。图片右键可复制、钉在桌面，Ctrl+C 复制，Esc 关闭；PSD/AI 的可见内容取决于原文件是否包含可用预览或 PDF 兼容数据。
- **项目画布**：左侧「项目」浏览画板缩略图。选中图片后「加入画布…」明确选择新建或已有项目；支持移动、缩放、绘图、文字、置顶和隐藏工具。
- **截图和翻译**：选区边缘可直接调整，旧标注可以重新编辑；截图功能在设置中选配。长截图在选区旁预览，完成复制、保存选路径，只有编辑才打开编辑窗口。
- **格式转换**：素材右键「转为」后点目标格式；生成独立副本，保留原件。外部文件可拖到「工具 → 格式转换」。额外引擎在设置中按需安装、更新和卸载，不保证任意格式互转。

## 浏览器收藏

「设置 → 浏览器收藏 → 安装 / 修复」准备固定插件目录，再按页内首次安装说明在 Chrome / Edge 确认加载。已有插件可以在同页一键更新；插件等待正在进行的收藏、编辑和弹窗结束后重载，以新版本实际连接回执为准。

0.2.27 改进升级后的重新连接与网页图片定位。实际验证了保持 Chrome 开着升级主程序、插件一键更新、原网页右键收藏及重复收藏；Grogu 页面产品照片能够保存正确的 WEBP。真实鼠标拖拽跨窗口尚未完成可靠的端到端验收，不能把右键收藏通过当作所有拖拽均通过。

换电脑需要重新配对，不复制旧电脑的密钥。插件随安装包提供，不在线下载远程执行代码。收藏结果不确定时保留状态，避免自动重发造成重复。

## 本版修复和验证边界

本版重点解决升级积累旧程序、入口指向旧版本、浏览器连接随安装路径变化、图库路由冲突，以及正常后台写入竞争误报保存失败。成功打开图片后显示复制、贴图与关闭的操作提示。

已完成虚拟机 0.1.29 → 0.1.30 的真实替换安装与插件 0.2.26 → 0.2.27 更新；旧程序清理、固定入口和原数据保留均有核对。之后的图库路由及图片提示改动通过 313 项定向检查；另保留旧代码负对照失败记录，未把失败记录改写成成功。详细范围和最终包状态见本版发布说明。

仍有待改善的地方：仅打开关闭画布可能更新项目排序；分类搜索入口不够明显；WEBM 缩略图、部分 SVG、密集小字 OCR 及复杂网站拖拽还不能保证。GitHub 下载到自动安装的全流程、多显示器和长时间资源趋势也未全面验收。历史版本测试不能作为所有功能或所有电脑通过的保证。

## 数据迁移

安装包不含你的素材。换电脑时先在旧电脑导出图库，新电脑恢复并选择图库；本地快捷收藏的原文件、贴图和完整画布目录需要分别迁移。新电脑已有内容时不要直接覆盖。详见 [使用说明的换机步骤](docs/使用说明.md)。

## 构建和许可

`build.ps1` 编译桌面程序；`-Test` 会运行程序测试，请在隔离测试环境使用。`package.ps1` 要求通过数据兼容性校验、带对应源码的滚动截图组件，以及已冻结验证的启动器；普通发布复用 `dependencies/update-launcher-v1`，不每次重建启动器。源文件使用固定 LF 换行，以免 Windows 检出改变兼容性校验值。

测试与开发用的数据、截图、配对文件、密钥及个人素材不属于发布内容。发布包提供 `SHA256SUMS.txt`，GitHub 更新还校验安装器身份和版本。
