# PDF / AI 阅读器界面参考

2026-10-30，按用户要求采用成熟阅读器的布局与交互。实现继续使用现有 WPF
阅读器和隔离渲染进程；没有引入第二套 PDF 引擎、在线服务或整套浏览器阅读器。

- Edge 官方 PDF 阅读器说明与界面图：https://learn.microsoft.com/en-us/deployedge/microsoft-edge-pdf
- PDF.js 阅读器结构：https://github.com/mozilla/pdf.js/blob/master/web/viewer.html

采用单排工具栏、左侧页码和可收起的缩略图导航、中央缩放、右侧次要操作。
使用 Nook 现有中性色与 Lucide 图标，按钮圆角 6 像素，不增加卡片装饰。
保留用户要求的连续滚动、8 像素页间距、不在正文页间显示页码和中键拖动。
选字复制 / 翻译仍是现有能力，不添加没有实现的搜索、批注或打印按钮。

页码输入 Enter 才跳转，错误输入留在原页；Esc 先取消输入。100% 采用原文档
的设备无关尺寸，避免重复把 Windows PDF 已换算的尺寸再乘 96/72。
整页适应支持不同长宽比的 AI 画板。专注模式只隐藏工具栏，不改变 OS 窗口；
F11、Esc 或右键都能恢复工具。

缩略图默认收起，展开后仅创建可见区域附近最多 12 个控件 / 160 像素小图；
正文渲染优先，缩略图复用已打开的受限渲染进程。收起或关闭即释放引用。
这只是缩略图缓存边界，不代表整个 PDF 进程的总内存占用。
