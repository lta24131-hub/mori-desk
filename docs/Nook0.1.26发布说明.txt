一、下载与安装
发布页：https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.26-preview
下载 Assets 中的 Nook-Setup.exe，不是 Source code。
使用 SHA256SUMS.txt 核对文件。Windows 10/11 x64；安装包未商业代码签名。
保存编辑后，使用“更多 → 退出 Nook”完全退出旧版，再运行安装包。
右上角 × 通常只是收进托盘。安装器不强杀旧进程，不删除旧版本或个人数据。
需要便携使用时，完整解压 Nook-0.1.26.0-portable.zip，再运行 Mori.exe。
不要只拿走一个 EXE；画布与部分视频需 WebView2，OCR 等有系统运行库要求。

本版沿用 MoriDesk 数据身份和已有图库／结果保存位置，不自动切回默认目录，
不改变 Windows 默认应用。新电脑不包含旧电脑的个人素材，空图库不代表丢失。
同样显示 0.1.26 的旧本地候选，应手动安装本次包，不能靠相同版本号区分。

二、最简单的转换操作
素材库：右键文件 → 转为 → 点目标格式。原件保留，副本加入当前图库，
继承分类等信息；常用目标在首层，其他能力在“更多格式”。转换时仍可浏览。
外部文件：工具 → 格式转换 → 拖入文件 → 点目标格式；不必先入库。
结果存到“设置 → 通用与存储 → 转换结果保存位置”，不替换原文件。
一次可转一个文件，少数批量场景也支持；只提供当前输入共同可用的目标。

图片／基础 PDF 核心随软件提供。视频、音频、Office、电子书等可能需要
“设置 → 转换组件”中的对应引擎；可按需安装、更新或卸载。
打开文件或检查格式不会自动下载全部组件。具体路线受输入与已装组件限制，
不是任意文件都能互转。高位深、图层、多音轨及排版可能发生变化，详见转换说明。

三、浏览器插件
安装包内有 Nook 插件 0.2.21，本轮连接修复保留其身份与版本号。
在“设置 → 浏览器收藏”检查连接并一键更新，等待插件确认；
相同版本号不代表当前浏览器副本已经替换。首次安装仍需浏览器人工确认。
不要复制旧电脑的配对文件到另一台电脑，也不要上传配对信息。

— 退出和后台收藏保护当前编辑草稿，不覆盖正在输入的备注／标签。

六、已知问题与尚未覆盖
— SVG 生产预览仍可能超时；WEBM 本例可播放但缩略图缺失。
— 大小字混排、小字 OCR 有明显漏识别；密集文字样例未完成。
— 截图自动识别区域仍有预算失败。长截图／双屏本轮未完整实际验收。
— 真实 Chrome、GPT 桌面拖入、Instagram 登录媒体及插件弹窗 UI 未齐。
— 供应商组件真实下载／更新／卸载、安装升级、OS 重启与长期压力仍待验证。
— 画布慢加载加入的确认超时边界，以及异常视频 worker 输出收尾仍需扩大验证。
— 不承诺所有格式、所有网站、所有电脑均可用，也不宣称安全漏洞已全部排除。
