Nook 0.1.30 验证候选记录 · 更新替换与浏览器收藏可靠性
主程序/安装器：0.1.30.0；浏览器插件：0.2.27。
本候选未公开发布；正式提供下载的后续预览版为 v0.1.31-preview。

本次变化
1. 使用固定启动入口，桌面、开始菜单、打开方式和浏览器本机连接不再跟着每次更新的版本目录改变。
2. 先准备并验证新程序，保存退出后切换；新主窗口确认健康后清理已核对身份的旧程序。保存失败、取消或启动失败时不提前删除旧程序。
3. 保护真实 Windows 用户数据路径和已有图库选择；不因运行环境或安装位置变化悄悄转到另一份空图库。素材、分类、贴图、画布和转换结果路径沿用原设置。
4. 浏览器插件升级后重新连接；改进页面图片目标定位，避免右键产品图却收藏到装饰图片。保留重复收藏检测和未确认结果保护。
5. 图库后台路由检查遇到正常写入竞争时稍后重试，不再误报“本次尚未保存”。真正的读写、权限和失效路由错误继续显示。
6. 图片成功解码后显示复制、钉在桌面和关闭提示；设计文件的预览限制仍可见。

验证范围
- 虚拟机实际完成 0.1.29 升级到 0.1.30：新版本健康确认后旧程序被清理，固定入口和原有数据库字段保留。
- 保持 Chrome 打开完成插件 0.2.26 到 0.2.27 一键更新；没有刷新原网页，右键收藏 Grogu 产品照片，实际保存正确 WEBP。再次收藏选择使用已有，数据记录没有重复。
- 后续后台路由及图片操作提示的定向回归 313 项通过。旧实现负对照有 14 项预期失败，用于确认检查能发现对应问题；负对照报告保留失败状态。
- 体验检查覆盖搜索、无结果恢复、图片预览、批量分类取消、选择新建或已有画布，以及已有画布打开关闭。不是全部功能或跨电脑全面验收。

已知边界
- 真实鼠标跨窗口拖拽未取得可靠的端到端自动化证据；不要把右键收藏测试当成拖拽全场景通过。
- GitHub 下载到程序内自动更新交接的完整在线流程未全面验收。
- 仅打开关闭画布可能改变项目修改时间和排序；分类搜索入口仍可优化。
- WEBM 缩略图、部分 SVG、密集小字 OCR、复杂网站、混合 DPI 多屏和长期性能仍有待继续改善。
- 为保护用户文件，混有未知文件、实际素材或正在使用文件的旧目录会被保留并提示；不会按目录名无条件删除。
- 未商业代码签名。包不含个人素材、设置、账号或配对秘密。

升级说明
安装器会拒绝覆盖已安装的相同或更高版本。已安装 0.1.30 候选的电脑，应使用后续 0.1.31 安装包升级，不用另一个 0.1.30 包覆盖。当前步骤见“使用说明.md”。
