## 安装向导

位置 → 可选组件 → 确认 → 安装/替换/清理记录 → 完成。开始前允许返回和取消，执行时可以最小化；等待用户退出、重试和点击完成时不持有安装事务锁。

首次安装可选独立程序目录；已有安装沿用原位置。浏览器连接随核心，Chrome 首次扩展安装仍需浏览器确认。可选增强 OCR、长截图、格式转换核心，后续引擎按需安装。

默认冻结启动器保持原字节；自定义路径启动器冻结在 `dependencies/custom-launcher-v1`。`368-custom-launcher` 验证了含空格路径、参数转发、跟随提交版本和 native messaging 标准输入输出。
