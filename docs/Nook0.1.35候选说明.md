记录日期：2026-10-30。主程序和安装器为 0.1.35.0，浏览器插件为 0.2.28。此说明记录封包前状态；最终安装与发布结果另附精确校验值。0.1.34 是较早的内部候选，本次递增版本，避免不同内容使用同一版本号。

本页保留封包时记录。后续精确程序、安装与发布结果见 [0.1.35 验证记录](Nook0.1.35验证记录.md)，下载与当前步骤以 [使用说明](使用说明.md) 为准。

## 使用体验

- 看图采用图片优先的布局：一行工具栏、底部缩略图、靠近左右边缘才出现的翻页箭头。缩略图没有卡片边框，当前图片只标一条紫色短线。参考 ImageGlass、PicView、QuickLook 的公开交互和界面资料，使用现有 Lucide 图标与许可。
- F11 隐藏工具栏和缩略图，图片适应当前窗口，不改变系统窗口大小；Esc 先恢复工具，再次 Esc 关闭。退出专注模式时恢复同一图片之前的缩放与位置。双击切换适应窗口 / 原始大小。
- 图库打开图片沿用当前筛选、排序和名称；快速翻页保留上一帧，最终显示最后一次选择。透明背景偏好保持生效。缩略图只加载相邻图片，限制缓存和解码并发。
- PDF / AI 参考 Edge 与 PDF.js 的成熟阅读器布局：单排图标工具栏、可输入的页码、缩放比例菜单、适应宽度 / 整页、按需展开的页面缩略图。F11 隐藏阅读工具，Esc 恢复。保留连续滚动、8 像素页间距、中键拖动及选字复制翻译；缩略图最多保留 12 张 160 像素小图，复用原渲染进程并让正文优先加载。
- 素材库滚动条加宽，拖动块有最小高度；滚远后可点回顶部，也支持 Ctrl+Home，保留当前选择。
- 截图画笔连续绘制不再每笔自动出现选中框；右键或 V 调整旧标注。默认尾部渐细实心箭头，另有线条与双向箭头。Ctrl+滚轮调粗细，Ctrl+Shift+滚轮细调，触控板小增量累积处理。
- 贴图悬停不显示菜单，右键调整；截图钉图入口移到右侧。首页、工具箱、选中素材操作和项目缩略图沿用本轮已完成的重排。

## 稳定性与性能

- PDF 原生渲染移入受限子进程，连续预览复用，关闭异步释放；此前复现的关闭后原生退出异常，在对应开发构建复测中正常退出。
- PDF 文字通信减少 JSON 中间对象和重复文本；保留原有文字提取、顺序、坐标、时间与内存边界。媒体子进程提前分流；默认程序仍是 Nook 时调用系统应用选择器，避免循环打开。
- 画布导入复用已解码尺寸，项目刷新后台读取，动图合并积压刷新；缩略图从解码位图直接传像素，减少 PNG 编码再解码。网站图标排队不占用线程池工作线程。
- 主图库和新快捷方式使用固定启动入口。旧任务栏项若直接指向历史版本目录，仍需取消固定后重新固定一次；不能保证任意旧项自动迁移。
