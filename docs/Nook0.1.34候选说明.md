# Nook 0.1.34 候选说明

记录日期：2026-10-30。主程序及安装器目标版本为 **0.1.34.0**，随附浏览器插件为 **0.2.28**。

**尚未发布。本文在完整包的安装、升级验收前写入，记录封包时状态。** 后续针对精确安装包的结果应附校验值单独记录，不把开发构建检查当作完整包已验收，也不为更新本文而改变已测试包的字节。上一已发布下载仍为 [0.1.33](https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.33-preview)，不含本次候选改动。

## 本次变化

- **首页与工具箱：** 素材添加、搜索、类型、排序和视图控制集中在浏览区域；选中素材后出现分类、画布、转换等操作。不常用的独立工具使用图标卡片；左侧“项目”继续显示画布缩略图。
- **筛选与缩略图：** 类型筛选无结果时也提供清除入口，保留当前分类或收藏范围。PDF、AI、受支持文本及 Office 文档可复用已校验的缩略图缓存；隐藏图库取消排队加载，恢复时按当前绑定重新调度并拒绝过期结果。
- **存储迁移取消与失败：** 恢复可见素材预览，不重置右侧详情、覆盖编辑草稿或额外保存素材信息。
- **桌面贴图：** 悬停不再显示工具栏或浮动按钮；右键提供旋转、翻转、复制、保存、打开图片或文字、关闭，翻译贴图保留翻译和重试。拖动、滚轮缩放、Ctrl+滚轮调透明度、历史找回仍可用。
- **截图钉图：** 右侧放置带少量主题色的图标，位于取消和完成之前，不显示按钮文字；窄选区保持操作相邻，遵守贴图选配与长截图准备状态。
- **浏览器提示：** 复用已收藏原件时不再错误报告“未分类”，明确选择分类时仍显示相应分类。

## 固定到任务栏

安装版主图库窗口和新安装快捷方式统一使用 `Nook.Desktop` 标识及固定入口 `Launcher\Mori.exe`。通过校验的升级候选在首次显示前设置该标识；便携版、测试预览、隔离窗口和独立图片、PDF、画布窗口不套用主图库标识。

**已有任务栏固定项不会被自动改写。** 直接指向历史版本目录的固定项，需要取消固定、从桌面或开始菜单打开 Nook 主图库，再重新固定一次。旧受管理入口具有转交兼容，但不能承诺所有更早固定项都有效。已检查窗口和临时快捷方式属性，尚未实际执行 Windows 任务栏固定 / 取消固定。

## 已知限制

**PDF 连续预览关闭时的原生退出异常尚未解决。** 虚拟机合成场景中，连续预览显示页面后关闭，或滚动缩放后关闭，会出现 `0xC000000D`；旧生产代码同样复现。单页渲染、立即取消正常，源文件未变且文件占用释放，均不能替代整个进程正常退出。

软件绘制与异步续接试验未解决异常，现有 `ntdll.dll` 错误信息不足以确定根因，还需原生异常调用栈。本轮没有合入未经证实的修复，没有用强制退出、强制 GC 或跳过测试掩盖问题，不能宣称 PDF 专项通过。

WEBM 缩略图、密集小字 OCR、复杂网站拖拽、画布排序与分类搜索继续保留改善空间。GitHub 下载到自动安装的完整交接、多显示器与长期资源趋势未全面验收；支持格式列表不代表全部格式或所有电脑均已测试。
