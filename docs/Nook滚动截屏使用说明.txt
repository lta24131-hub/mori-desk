Nook 0.1.25 预览版 · 滚动截屏与截图操作

滚动截屏
1. 按截图快捷键，在一个显示器内框选要拼接的内容区域。
2. 点击工具栏“滚动截屏”图标；选区旁显示纯图片预览，选区下方固定四个图标：
   编辑、保存、取消、完成。预览和控制不跟随鼠标。
3. 把鼠标放在原选区内滚动原页面，不需要逐张追加。滚动模式下滚轮不调整画笔。
   预览随长图增长在屏内等比显示完整结果，空间不足时自动调整位置。
4. 停止滚动后会补取尾帧。核对预览后，点“完成”直接复制；
   点“保存”选择图片位置；只有点“编辑”才打开普通可移动、缩放的编辑窗口。
   编辑窗口不是全屏截图遮罩，原有标注继续作为可编辑对象保留。
5. 编辑后可复制、保存、贴到屏幕或收藏到素材库。保存取消、输出失败时保留结果，
   方便继续调整或重试；成功后才关闭，连续点击不会重复提交。
6. 点“取消”或按一次 Esc 结束整次截图。系统“另存为”窗口里的 Esc
   仅取消选择路径，回到截图结果，不丢弃长图。

功能选配与启动速度
- 打开“设置 → 截图与翻译 → 截图功能”，共 13 项：
  矩形、椭圆、箭头/直线、画笔、文字、马赛克、自动识别选区、提取文字、
  截图翻译、滚动长截图、长截图快速启动、钉在桌面、收藏到素材库。
- “基础截图”关闭可选项；“全部开启”恢复完整工具。保存后下一次截图生效，
  无需重启。框选、调整边框、复制、保存与 Esc 始终保留。
- “长截图快速启动”默认开启，仅在滚动长截图启用时有效。普通截图显示后提前
  加载隐藏组件，不读取屏幕，不提前注册全局输入钩子。未使用时最多闲置约 120 秒，
  取消、结束截图或退出软件时释放；需要更多临时内存，实际占用取决于机器与任务。
- 不需要预热时取消勾选；点击滚动截屏时再启动。关闭功能不会卸载组件或模型，
  不影响已有贴图与独立输入翻译，不承诺所有机器零等待或相同内存占用。

注意
- 请保持窗口大小、选区与页面缩放不变，优先沿同一个方向缓慢滚动。
- 每一屏至少需要保留上一屏约 20% 的内容。快速跨过多屏、动画、视频、重复图案可能无法可靠拼接。
- 拼接结果请看实时预览确认；重复图案、动画和跨屏快速跳动仍可能影响匹配。
- 按“完成”前留意尾部内容；补取尾帧是减少滚动停止后的漏采，不保证每个动态页面准确。
- 建议框选实际滚动内容，避开会变化的悬浮工具条。完全不变、有纹理的顶部/底部工具栏会尝试去重。
- 单次最多 6400 万像素，任一边最多 32768 像素。达到上限会提示并保留已有结果，
  不静默复制截断内容；由你确认输出后再分段截图。
- 鼠标位于原选区内时，滚轮滚动原页面，不调画笔。进入编辑后才恢复编辑工具。
- 组件启动失败或意外退出时恢复原截图和标注，不会丢弃原编辑。
- 如 Esc 被其他软件占用而无法注册，滚动模式会停止启动并保留原截图，不进入无法取消的会话。
- 取消保存或收藏失败时保留长图预览，方便重试。
- 仅在本机处理；没有后台上传页面内容。

一次 Esc 退出
- 普通选区、画线、画笔、选中文字、正在输入文字、语言菜单或翻译中，按一次 Esc 直接退出整次截图。
  系统保存对话框里的 Esc 按上述系统约定处理。
- 双屏的截图层一同退出。滚动截屏时即使目标应用获得焦点，也可以按一次 Esc 取消。
- Esc 不会提交未完成的标注。已经明确提交到素材库的收藏可能继续完成，不会因此关闭下一次截图。
- 右键仍用于逐步取消当前手势/工具或重新选择区域，不再让 Esc 承担逐层返回。

直接调整边框
- 工具栏不再显示“选择/调整”按钮。
- 使用矩形、椭圆、箭头、画笔、文字、马赛克等工具时，也可直接拖动截图四边与四角。
- 鼠标靠近边缘会显示相应缩放光标；拖动完成后保留当前画图工具。
- 边框调整支持撤销、重做，已有标注保留。
- 旧标注可直接重选与移动，文字可双击重编；文字字号与画笔粗细分开。
  普通滚轮不误改标注，识字返回后保留原图、标注与撤销历史。
