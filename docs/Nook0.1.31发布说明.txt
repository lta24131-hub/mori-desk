Nook 0.1.31 预览版 · 更新替换与浏览器收藏可靠性
主程序/安装器：0.1.31.0；浏览器插件：0.2.27。
发布标签：v0.1.31-preview

本次变化
1. 使用固定启动入口，桌面、开始菜单、打开方式和浏览器本机连接不再跟着每次更新的版本目录改变。
2. 先准备并验证新程序，保存退出后切换；新主窗口确认健康后清理已核对身份的旧程序。保存失败、取消或启动失败时不提前删除旧程序。
3. 保护真实 Windows 用户数据路径和已有图库选择；素材、分类、贴图、画布及转换结果路径沿用原设置。
4. 改进浏览器插件升级后的连接和页面图片目标定位，避免右键产品图却收藏到装饰图片。保留重复收藏检测和未确认结果保护。
5. 图库后台路由检查遇到正常写入竞争时稍后重试，不再误报“本次尚未保存”；实际读写、权限或失效路由错误仍显示。
6. 图片成功打开后显示复制、钉在桌面和关闭提示；设计文件的预览限制继续保留。

版本与验证范围
- 0.1.30 是验证候选，未公开发布。安装器会拒绝覆盖相同或更高版本，因此公开包递增为 0.1.31，允许已有 0.1.30 候选正常升级。
- 0.1.31 复用已冻结候选的功能源码，只递增主程序、安装器版本并同步文档。以前的测试保留其实际版本边界，最终包的安装验收以发布页说明为准。
- 之前已在虚拟机完成 0.1.29 → 0.1.30 替换安装、插件 0.2.26 → 0.2.27 一键更新、Grogu 页面正确 WEBP 右键收藏与重复复用，原数据库字段保持。
- 后续后台路由与图片操作提示的定向回归 313 项通过；旧实现负对照保留 14 项预期失败，未改写为成功。
- 体验检查包括搜索、无结果恢复、图片预览、批量分类取消、画布目标选择和已有画布打开关闭，不等于全部功能或跨电脑全面验收。

已知边界
- 真实跨窗口拖拽和完整 GitHub 自动更新交接尚未全面验收。
- 仅打开关闭画布可能改变项目修改时间和排序；分类搜索入口仍可优化。
- WEBM 缩略图、部分 SVG、密集小字 OCR、复杂网站、混合 DPI 多屏和长期性能仍待改善。
- 旧目录混有未知文件、实际素材或仍被占用时保留并提示，不按名字无条件删除。
- 安装包未商业代码签名，不含个人素材、设置、账号或配对秘密。

安装
下载 Nook-Setup.exe，保存编辑并正常退出旧 Nook 后运行。安装器保留现有图库和保存路径，新主窗口确认健康后清理已核对的旧程序。
便携版完整解压 Nook-0.1.31.0-portable.zip 后运行 Mori.exe，不要只复制单个 EXE。
浏览器插件在“设置 → 浏览器收藏”检查实际连接版本，需要时点一键更新；首次安装仍由浏览器确认。
