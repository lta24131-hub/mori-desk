# 2026-11-04 浏览器收藏结果反馈

## 问题与改动

原提示位于网页右下角，字号小、成功仅停留 1.8 秒，名称和分类藏在悬停提示中。拖图松手后，收藏框消失，保存中提示还要等待 500 毫秒，容易让人误以为没有响应。

- 松手立即显示“正在收藏…”，结果卡片留在收藏框附近。
- 成功卡片显示绿色勾、可用的网页图片预览、真实保存名称和分类；预览失败回退为状态图标，不改变保存结果。
- 成功保留 7 秒、失败保留 15 秒；鼠标悬停或键盘焦点在卡片内时暂停倒计时。等待保存不自动消失。
- 连续收藏最多保留 3 张卡片；下一次拖动时卡片不拦截鼠标，取消或结束拖动后恢复交互。适配窄窗口及浅深主题。
- 右键收藏共用成功反馈。失败、重复选择和结果不确定仍保留各自状态，不自动重新保存。
- 新桌面桥接支持“打开 Nook”，仅启动固定入口，不接受网页传入的路径或参数。旧桌面端未声明能力时不显示按钮；打开失败不把已完成的收藏报告为失败。
- 插件版本为 0.2.29，身份密钥未变。打开按钮只打开主窗口，不承诺按素材 ID 定位。
