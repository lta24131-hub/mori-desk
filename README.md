# Nook · 0.1.47 预览版

本版随包提供韩文文字识别模型。截图和图片文字窗口的翻译按钮恢复为图标，悬停可查看当前操作，点击同一个按钮可在原图和译图之间切换。

Windows 10/11 x64 的本地工具集合：素材收藏、图片与文档预览、截图翻译、项目画布、贴图、3D 查看和格式转换。

主程序及安装器 **0.1.47.0**，随附浏览器插件 **0.2.31**。

## 安装和更新

1. 打开随本版提供的 `Nook-Setup.exe`。已有 Nook 时，先保存编辑内容并从「更多 → 退出 Nook」正常退出；右上角 × 可能只是收进托盘。
2. 按向导选择安装位置和可选组件，确认后在同一窗口查看安装与清理进度；开始前可返回修改。已有安装沿用原位置。安装后使用桌面或开始菜单中的 Nook，保留图库、设置、贴图、画布及已选保存路径，不把 D 盘图库重新变成 C 盘空图库。
3. 已有安装版可直接打开「设置 → 关于与更新」，勾选「包含预览版本」，点「检查更新」。先保存编辑内容，再点「下载并重启更新」。下载和校验完成后会准备备份并正常退出，准备阶段可以取消。

更新采用固定启动入口，内部先准备并验证新程序，正常保存退出后切换。新主窗口确认启动成功后，清理已核对身份的旧程序文件；不因同名目录就删除内容。失败时保留旧程序及恢复入口。旧目录混有素材、未知文件、正在使用的程序或校验不符时会保留并提示，不承诺删除所有历史文件。备份不等于完整素材副本。

从 0.1.38 起，新版健康启动并确认入口就绪后，还会清理 Nook 自动下载并已用过的安装包；未使用的下载和中断残留满 7 天可清理。更新元数据保留最近一次成功且完整的备份，较早的成功备份自动清理。失败、不完整、被修改或正在使用的内容保留。手动放在桌面、下载文件夹等位置的安装包不会自动删除。可在「设置 → 关于与更新」查看维护结果。

安装版主图库窗口和新快捷方式统一到固定启动入口 `Launcher\Mori.exe`。**已有任务栏固定项不会自动改写**：若它指向历史版本目录，需要取消固定后重新固定一次。旧受管理入口的转交兼容不能保证任意更早固定项都有效；实际任务栏固定 / 取消固定尚未完成本轮验收。

便携包为 `Nook-0.1.47.0-portable.zip`，完整解压后运行 `Mori.exe`。兼容文件名沿用 Mori，不要只复制单个 EXE。便携版采用手动更新，不注册 Windows 图标组件。安装器拒绝降级或用不同内容覆盖相同版本。

环境：Windows 10/11 x64、.NET Framework 4.8；画布、3D 和部分视频使用 WebView2，OCR 组件可能需要 Visual C++ x64 运行库和相应语言包。安装包尚未商业代码签名。

## 日常使用

- **素材库**：拖入图片或文件，分类、搜索、多选整理；本地快捷收藏保留原文件地址。文件夹快捷方式留在本地收藏，避免当成图片素材混入全部素材。
- **图片和文件预览**：打开图片、视频、PDF、文本及支持的设计文件。图片右键可复制、钉在桌面；PDF / AI 采用紧凑工具栏、页码跳转和可收起的页面缩略图，保留连续滚动与中键拖动。F11 在当前窗口内隐藏工具，Esc 先恢复工具、再关闭；PSD/AI 的可见内容取决于原文件是否包含可用预览或 PDF 兼容数据。
- **项目画布**：左侧「项目」浏览画板缩略图。选中图片后「加入画布…」明确选择新建或已有项目；支持移动、缩放、绘图、文字、置顶和隐藏工具。
- **截图和翻译**：选区边缘可直接调整，旧标注可以重新编辑；截图功能在设置中选配。右侧钉图图标位于取消、完成之前。贴图悬停无工具栏，右键调整；拖动移动、滚轮缩放、Ctrl+滚轮透明度仍可用。长截图在选区旁预览，只有编辑才打开编辑窗口。
- **格式转换**：素材右键「转为」后点目标格式；生成独立副本，保留原件。外部文件可拖到「工具箱 → 格式转换」。额外引擎在设置中按需安装、更新和卸载，不保证任意格式互转。

## 浏览器收藏

「设置 → 浏览器收藏 → 安装 / 修复」准备固定插件目录，再按页内首次安装说明在 Chrome / Edge 确认加载。已有插件可以在同页一键更新；插件等待正在进行的收藏、编辑和弹窗结束后重载，以新版本实际连接回执为准。

0.2.28 修正重复收藏复用原件时的分类提示，不再把未知原分类误报为“未分类”。0.1.35 的虚拟机升级曾验证保持测试 Chrome 打开后继续连接及右键收藏 PNG；本次插件代码不变，这条历史记录不代表所有网站重新验收。真实跨窗口拖拽、复杂网站的全部图片类型仍未全面验收。

换电脑需要重新配对，不复制旧电脑的密钥。插件随安装包提供，不在线下载远程执行代码。收藏结果不确定时保留状态，避免自动重发造成重复。

## 截图翻译

- 框选按钮后点工具栏的翻译图标。默认使用腾讯译成中文时，18 个常用英文单词可直接显示菜单释义，例如 `Rename` 显示「重命名」。同一个词出现在句子中时按整句翻译。看图及桌面贴图也使用这组释义。
- 单行先核对文字笔画和边界，有足够证据才采用快速识别。密集页面及无法核对的单行交给完整识别模型。原图有截字或近形字时，仍可检查并修改识别文字。
- 可在翻译时取消，看到译文后直接复制，或切回原图对照。部分译文放不下时可打开「完整译文」。已有译文遇到排版超时，再次点翻译图标即可重排已有译文。

0.1.46 在 Windows 开发虚拟机的实屏专项中，从点击到看见中文，两个新进程的首张 `Open`、`Download` 分别用了 **1.57 秒、1.55 秒**。连续截取未见过的 `Copy`、`Save`、`Rename` 各用 **0.88–0.94 秒**。首次普通在线短句仍有明显等待，桌面电量提示用了 **5.80 秒**，浏览器「Open this file.」用了 **6.62 秒**。

另在带正式组件的兼容环境完成两套回归，截图套件通过 2,294 项，全应用套件通过 97 个阶段、14,379 项。两套计数各自统计。具体样本、组件和计时条件见[截图翻译复测](docs/20261120-截图翻译复测.md)。

## 数据迁移

安装包不含你的素材。换电脑时先在旧电脑导出图库，新电脑恢复并选择图库；本地快捷收藏的原文件、贴图和完整画布目录需要分别迁移。新电脑已有内容时不要直接覆盖。详见 [使用说明的换机步骤](docs/使用说明.md)。

## 构建和许可

`build.ps1` 编译桌面程序；`-Test` 会运行程序测试，请在隔离测试环境使用。`package.ps1` 要求通过数据兼容性校验、带对应源码的滚动截图组件，以及已冻结验证的启动器；普通发布复用 `dependencies/update-launcher-v1`，不每次重建启动器。源文件使用固定 LF 换行，以免 Windows 检出改变兼容性校验值。

测试与开发用的数据、截图、配对文件、密钥及个人素材不属于发布内容。发布包提供 `SHA256SUMS.txt`，GitHub 更新还校验安装器身份和版本。
