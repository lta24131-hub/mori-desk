# Nook · 0.1.23 预览版

Windows 10/11 x64 的本地工具集合。单个安装包，统一素材窗口和托盘；3D 与独立看图按需启动，OCR 使用短期工作进程。

本次发布 **Nook 0.1.23.0**，随附浏览器插件 **0.2.21**。下载：[v0.1.23-preview](https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.23-preview)。仓库保持**私有**，需要登录有访问权限的 GitHub 账号。本次程序与已经安装验收的截图、双屏优化版一致；安装程序不会自动替换浏览器中已加载的扩展。

## 当前本机版本与已发布安装包

下载 `Nook-Setup.exe` 安装；或完整解压 `Nook-0.1.23.0-portable.zip` 后运行 `Mori.exe`。使用指南为 `Nook-Guide.txt`，另有文件校验清单 `SHA256SUMS.txt`。插件已包含在安装包内，也提供单独 ZIP；其中不含本机配对文件。程序包不含个人图库、缓存、设置及可选语言包。保留 `Mori.exe` 文件名、`MoriDesk` 数据目录和 `app.mori.desk` 本机连接身份，避免品牌改名导致已有数据或配对丢失。

本轮配色以白色 / 中性黑灰为主；外观可选择浅色或深色，以及紫、蓝、青、琥珀、玫瑰、灰六种强调色，共 12 种组合。强调色仅用于选中、焦点和少量重点操作，不给素材或译文大区域重新着色。沿用自动选框优先大区域、层级保持与边界滚轮修复，没有新增大型运行依赖。上一版测试范围见 [0.1.20 验证记录](docs/Nook紫色主题与选框验证.txt)，不能代替本轮测试或跨电脑验证。

按项目保存、可置顶的自由画布，以及低调的网址快速浏览：双击收藏网址在主窗口里浏览，返回保留列表状态；单张图片右键可设置为桌面壁纸或钉在桌面。说明与第三方许可见 [画布与快速浏览](docs/画布与快速浏览.md)。画布使用固定版本的本地前端，通过现有 WebView2 承载，不另装浏览器内核。

左侧「项目」直接显示一个个画板的缩略图，可打开、新建、重命名和整理项目。选择图库图片后点「加入画布…」，明确选择新建画布或已有项目，不会直接塞进最近打开的项目。画布提供选择、手掌、自由绘制、直线、箭头、几何图形、文字及选中对象的样式调整；图片与绘图可拖动、缩放、对齐、撤销与自动保存。顶部保留置顶和隐藏工具的图标入口。

图库图片拖到左侧「项目」可展开项目页，再拖到具体画板并松开；电脑图片文件也可拖到目标画板。悬停不导入，松开时重新核对素材和目标；在侧栏或项目页空白处松开不会误存到图库。未保存信息、忙碌操作或保存失败均有守卫，不丢弃草稿，不对隐藏的图库选中项执行操作。新建、切换和退出前先保存当前画布；失败时保留编辑内容。

图片成为画布独立附件，不删除图库或电脑原件。SVG 和 PDF 兼容 AI 在画布中保存为最长边 2048 像素的 PNG；**AI 只加入首个 PDF 兼容页面，不是全部画板或图层**。GIF 为静态首帧，文件夹不展开，视频和文档不作为画布图片添加。数量没有四张限制，但仍受电脑资源约束。

截图与双屏候选通过 **2415 项后台断言**，两块 100% 缩放屏幕完成鼠标流程实测：分别选区、右键清除后换屏重选、工具栏靠边避让及整次退出。隔离测试入口到两屏显示的两次观测约为首次 0.36 秒、预热后 0.20 秒，不是系统全局快捷键端到端基准。不同缩放屏幕的真实落点仍待实机验证，当前不支持一个选区横跨两块屏幕。历史检查计数不累加，也不作为新版本的跨电脑保证。

已在备份后完成本机安装与只读数据保全核对：数据库、分类、快捷收藏、画布文件、贴图原图和清单、设置及配对均保留；桌面 / 开始菜单与既有自启动指向新版，只有一个正式主进程，本机浏览器接收端正常监听。这不代表所有网站、所有编码格式或其他电脑已完成验收。

设置整理为七组：通用与存储、外观、素材浏览、文件预览、截图与翻译、自由画布、浏览器收藏。新增透明图片背景、动图播放、音视频初始音量 / 静音 / 自动播放 / 循环、网址打开方式，以及画布默认置顶、自动保存延迟和图片缓存预算。预览与画布设置保存后对新打开的窗口生效，不打断正在使用的窗口。

1. 在浏览器登录有权限的 GitHub 账号，打开 [0.1.23 下载页面](https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.23-preview)。仓库继续私有，未登录或账号无权限时可能显示 404。

3. 双击安装，完成后打开桌面上的 **Nook**。本版不覆盖独立旧 Mori / Luma；安装包不包含旧电脑的个人素材，新电脑首次打开空图库是正常的。

## 开始使用

以下操作以 Nook 0.1.23 为准。安装时双击 `Nook-Setup.exe`；或完整解压便携包，运行兼容文件名 `Mori.exe`。不要单独复制 EXE。通常无需管理员权限；需要 Windows 10/11 x64、.NET Framework 4.8、WebView2 Runtime（画布、3D / 部分视频）、Microsoft Visual C++ 2015–2022 x64 运行库（OCR 依赖），中文识别还需 Windows 相应 OCR 组件。

- **素材库**：全部素材汇总图片、动图、视频、音频和模型，含符合类型的本地快捷收藏；网址和文档有独立入口。点“导入素材”、网页收藏和图片粘贴保存副本；普通电脑文件拖入默认只记位置。右侧最下面显示本地地址及保存方式。保留分类、撤销、批量操作等功能。
- **本地收藏**：拖入任意文件 / 文件夹，仅记录路径；文件夹内容不递归导入。大文件夹与小文件图块分开，空白处右键可新建分类文件夹；拖入分类只整理快捷收藏，不移动原件。Ctrl/Shift 多选，Delete 移除收藏，Ctrl+Z 撤销。移除收藏不删除原件，解散分类保留内容。原件改名、移动或换电脑后仍依赖原路径；F5 可刷新。搜索、排序、筛选复用已加载元数据，编辑信息时暂缓刷新保护草稿。
- **工具 → 截图**：标注、原位翻译、OCR 文字选择、贴图与“收藏到素材库”；工具条分组，支持撤销 / 重做、标注重选与文字重新编辑。选区右键分阶段返回后可换屏重选，不重新捕获遮罩。新贴图适配鼠标所在屏幕；Shift+F3 显示 / 隐藏全部贴图，重启恢复仍启用的贴图。
- **工具 → 输入翻译**：保留腾讯 / Google / 可选离线中英包、语言包管理。在线翻译发送文字到所选服务，不应输入保密内容。
- **工具 → 打开图片**：不自动收藏；滚轮缩放，拖动查看，左右键切换同文件夹图片，双击或 Esc 关闭。GIF 可播放，SVG 使用隔离渲染。
- **工具 → 打开 3D 模型**：STEP/STP、STL、OBJ、GLB、3MF。本地加载，旋转、缩放、材质、结构线、坐标方向、全屏。大模型仍受机器内存和 STEP 解析复杂度影响，不保证秒开。
- **PDF / PDF 兼容 AI**：连续预览中按住中键拖动页面，横向和纵向均可移动；松开中键停止，Ctrl＋滚轮缩放。左键仍用于开启选字后的文字拖选，不改成页面拖动。
- **自由画布**：左侧「项目」管理画板，工具入口、图片右键或多选后的「加入画布…」可新建或指定已有项目；支持图片拖入和 Ctrl+V 粘贴。Del 只移除画布对象，Ctrl+Z 撤销，Esc 取消未完成手势；停止编辑后延迟自动保存。中键或空格拖动平移，Alt+滚轮缩放；顶部图标可置顶或隐藏工具。新建 / 切换前保存失败会停留在当前画布。

主窗口默认关闭后收进托盘，可在「设置 → 通用与存储」关闭此行为；托盘或“更多”菜单的 **退出 Nook** 完全退出主程序，先保存自由画布，未完成的截图退出前询问。画布正在导入或保存失败时暂缓退出，不丢弃未保存内容。已独立打开的看图 / 3D 窗口由各自的关闭按钮退出，不随主窗口的隐藏而消失。只看图不需要图库在前台。同时打开不同图库时，只有一个主窗口拥有截图快捷键和贴图；该窗口完全退出后，另一个窗口自动接管，避免重复恢复和写入贴图。

## 文件与安全

- 默认数据继续使用 `%LOCALAPPDATA%\MoriDesk`。从集合软件 Mori Desk 更新为 Nook 时沿用该目录，图库、贴图、设置和配对保留；不是重新建立空图库。默认图库在其中的 `Library`，可在设置中更改/整体迁移。
- 贴图、翻译设置和可选语言包在集合软件的数据目录内，**不读写独立旧 Mori 或 Luma 的数据**。
- 本地收藏保存在当前图库数据库中；图库备份含这些引用，**不包含引用的原件**。换电脑时必须另行迁移原件，保证相应路径可用。
- 自由画布保存于数据目录的 `free-canvas`，布局与独立图片附件不在现有图库备份中。换电脑需完全退出后另行迁移该目录，不要把图库备份当作整套软件备份。
- 素材库撤销保留当前会话最近 30 步，使用有容量上限的元数据差异记录；画布有独立的当前项目撤销记录。重启后不保留撤销历史。
- 本版没有自动迁移旧软件、卸载旧版、自动云同步、主程序自动更新或默认文件关联。安装包未进行商业代码签名。
- 旧 Luma 正在运行时可能占用 F1 / F3 / Ctrl+Alt+T；请先通过工具菜单体验，确定替换后再统一快捷键。

## 浏览器收藏插件

随附 Nook 插件 0.2.21 保留拖拽、右键收藏和浏览器书签导入，沿用本机连接 `app.mori.desk`、扩展身份和本机配对，不覆盖独立旧 Mori。安装主程序不等于已更新真实插件。

1. **设置 → 浏览器收藏 → 安装 / 修复**，再展开首次安装说明。新安装使用固定目录和固定身份，不需要手动输入 ID。
2. 首次在 Chrome / Edge 扩展管理页确认加载；旧插件第一次升级仍需重新加载一次。原插件身份及偏好设置会保留。
3. 之后安装新版 Nook，在同一设置页点 **一键更新**。插件等待收藏和编辑结束、弹窗关闭后安全重载；收到新版本确认才显示完成。

更新仅来自随 Nook 安装的插件文件；无远程代码下载。更新控制不访问或初始化图库。多个浏览器同时使用同一插件目录时暂缓更新；保存结果不确定时，需要用户先核对，不会自动重发收藏请求。

浏览器本身要求确认安装扩展，所以换电脑后此步骤仍需手动执行。未授权前本程序不会修改你的浏览器。

## 本轮改进与许可

0.1.23 汇总项目缩略图、新建或指定画布、画布可靠保存、独立看图生命周期、钉图及恢复、打开方式修复，以及截图标注和双屏交互优化。保留中性黑白灰与六种小面积强调色、媒体预览偏好、PDF / AI 连续预览和中键拖动。图片增强不读取全部编辑图层；扫描件仍需截图识别。随附插件 0.2.21 保留扩展身份和配对；安装包携带插件不表示浏览器已经替换它。

画布基于固定 **2.4.6** 版本，适用其随附的**非商业许可**，不是 MIT，也不能因为源码可见就用于商业用途。模块声明与完整许可见 [画布 NOTICE](web/canvas-src/THIRD-PARTY-NOTICES.txt) 和 [固定版本许可](web/canvas-src/licenses/tldraw-2.4.6-LICENSE.md)。本次仅供个人非商用；商业运营或商业机构内部使用需另行取得适用许可。其他组件保留各自许可。

既有改进仍保留：保护未保存备注、分类撤销及本地分类目标；图片后台加载、关闭取消排队、隐藏暂停 GIF；3D 换图取消前一份读取；插件不自动重发未确认的收藏。不开启大型常驻组件，不声称总解码耗时或常驻内存一定下降。完整累计更新见版本说明。

换电脑后首次安装插件仍需浏览器人工确认；现有电脑更新时先备份、保存编辑内容并完全退出。旧版菜单为“退出 Mori Desk”，新版为“退出 Nook”。主程序更新不要求同时替换正常连接的插件；确需升级时再从“设置 → 浏览器收藏”操作。自启动以设置中的实际状态为准，不能因为安装而开启原本关闭的自启动。不要把旧电脑的浏览器配对文件搬到另一台电脑覆盖。

换机迁移顺序：旧电脑用图库管理导出 `.mori.zip` → 新电脑恢复到空文件夹并选择该图库 → 另行搬迁本地快捷收藏引用的原件 → 两端完全退出后迁移 `capture` 和完整 `free-canvas` 目录 → 新电脑重新连接浏览器插件。图库备份不包含贴图、画布或外部原件；新电脑已有这些内容时先备份，不直接覆盖。详细步骤见 [使用说明第八节的换电脑搬迁](docs/使用说明.md)。

[测试与体验检查](docs/体验检查.md) 记录对应版本的验证结果和剩余限制；旧版记录不作为 0.1.23 的测试结论。

## 开发与测试

`build.ps1 -Test` 编译并运行本地收藏、安全及路由测试。
`Mori.exe --self-test <新的测试目录>` 运行原素材库回归检查。
`Mori.exe --integration-test` 使用合成英文图片验证 OCR 子进程、腾讯双向翻译及原位渲染，产生测试报告（需联网）。
`Mori.exe --ui-test <测试图库>` 打开隔离窗口，不注册全局快捷键或托盘。
`package.ps1` 生成有文件白名单的便携 ZIP 和单文件安装器，不包含个人素材、设置、截图、贴图或 API 密钥。

桌面源码来自 Mori、Luma 的独立副本，3D 网页部分以预构建的离线资源包含在 `web/model` 中；构建桌面程序不需要重新构建该网页。原项目保持不动，第三方许可随包附带。
