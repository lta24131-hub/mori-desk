# 自由画布与快速浏览

本说明针对 Nook 0.1.22 候选版，尚未安装或发布。本机已安装 0.1.21；本轮新增多选画布和绘图工具需更新后生效。候选源码、测试、安装和 GitHub 发布是不同步骤，本说明不代替对应构建的最终测试报告。

## 自由画布

入口为「工具 → 自由画布」。多选图片后，右侧直接点击「画布」加入当前项目；原「并排比较」入口已替换，不限制 2–4 张，也不每次强制新建项目。单张或多张图片仍可右键「加入自由画布」。主页仍以素材库和网址收藏为主。

- 按项目创建、打开、另存和重命名画布。停止编辑后按设置延迟自动保存，也可点击「保存」。删除项目前会确认，项目移入画布自己的回收目录，可从项目菜单恢复最近删除的画布；不删除图库或电脑上的原图片。
- 可从电脑拖入图片，也可从图库右键加入。支持来源应用提供可读取数据的桌面虚拟图片拖入，以及 Ctrl+V 粘贴图片 / 图片文件；不递归导入文件夹。仅有需登录的链接、没有可读图片数据时不保证能接收。画布不沿用旧并排比较的 4 张限制；实际规模仍受磁盘、内存和图片解码能力影响，单张文件上限为 256 MiB，桌面虚拟图片接收另有安全大小限制。
- 选择工具下拖动图片；用四角控制点等比缩放。Ctrl 可以多选；Del 只从当前画布移除选中对象。Ctrl+Z 撤销画布内操作，不作用于素材库。
- 滚轮缩放画布；中键拖动或按住空格拖动平移。文字输入时空格和 Del 保留正常编辑行为。
- 第二行工具条提供自由画笔、直线、箭头、空心矩形、椭圆和文字；颜色和粗细只影响新标注。画完可继续画，切回「选择」可移动、删除标注；Ctrl+Z 撤销，Esc 取消当前未完成的手势。
- Ctrl+S 或点击「保存」会完成当前手势并保存，之后可 Ctrl+Z 撤销；Esc 不会撤回已经保存的操作。
- 这是基础绘图，不是完整矢量编辑器；双击文字可编辑。原图不会被覆盖或重新着色，GIF 在画布中只显示静态首帧，独立看图的动图播放设置不改变这一点。
- SVG 和带 PDF 兼容内容的 AI 会转换为最长边不超过 2048 像素的独立 PNG 预览。AI 只加入首页 / 首个兼容画板，不合并全部页面；画布不编辑原来的矢量或图层。没有 PDF 兼容内容的 AI 会明确提示，不加入空白图片。
- 「置顶」让画布保持在其他窗口上面，项目会保存自己的置顶状态。主窗口默认关闭收进托盘后，画布仍可继续使用；完全退出 Nook 时会先保存画布。正在导入或保存失败时会暂缓关闭，保留尚未保存的内容。

### 画布偏好

「设置 → 自由画布」可设新项目默认置顶（默认关闭）、自动保存延迟（停止编辑后默认 1.2 秒，范围 0.5–10 秒）、图片预览缓存（默认 48 MiB，范围 16–128 MiB，界面标为 MB）。设置保存后在下次打开画布时生效；已有项目自己的置顶状态优先。低缓存预算节省解码图片缓存，高预算减少重新加载，但都不是软件总内存上限，也不限制图片数量。关闭时仍会主动保存，不必等自动保存延迟。

画布数据与当前图库分类分开，保存在 `%LOCALAPPDATA%\MoriDesk\free-canvas`。图片保存为画布的独立附件，避免原件移动导致参考图失效，因此会占用一份额外磁盘空间。预览采用可见区域加载和受预算控制的缩略解码，不把每张原图全部解码后常驻。

换电脑时，除了图库，还需要迁移此画布数据目录。现有「备份整个图库」只备份图库，不能当作整个 Nook 设置、贴图或画布的完整备份。不要把浏览器配对密钥复制到另一台电脑覆盖。

## 收藏网址快速浏览

- 默认双击网址收藏，或选中网址按空格，在软件内快速浏览；左侧导航仍保留。可在「设置 → 文件预览」关闭“双击网址时在 Nook 内快速浏览”，这两种操作都改用默认浏览器，右键仍可选择打开方式。
- 用左上角「返回收藏」回到原来的分类、搜索和选中状态，同时释放网页浏览资源。切换左侧页面也会关闭当前网页。
- 网址右键「用外部浏览器打开」继续使用 Chrome / Edge 的登录状态和插件。
- 「工具 → 快速浏览网址」是备用入口，没有显眼的浏览器工作区标签。地址栏支持网址和关键词搜索，关键词搜索会发送给 Bing。
- 浏览器有前进、后退、刷新 / 停止、收藏当前网址和外部打开。不会自动收藏网页。

此功能使用软件原有 WebView2 运行时，打开网页才启动，收进托盘时暂停。网页使用独立的 `WebViewBrowser` 配置目录，不读取 Chrome 个人资料或共享 3D / 视频预览的配置。网页不能调用图库接口；文件及其他本机协议、自动弹窗、下载、摄像头和麦克风请求会被阻止，也不会绕过证书错误或自动保存密码。复杂登录、下载、网站兼容问题请切到外部浏览器，不保证所有网站可用。

## 预览和外观设置

设置分为通用与存储、外观、素材浏览、文件预览、截图与翻译、自由画布、浏览器收藏七组。「外观」可组合浅色 / 深色与紫、蓝、青、琥珀、玫瑰、灰六种强调色，共 12 种组合；底色仍是中性黑白灰，强调色只用于少量交互，不修改图片或网页内容。外观即时预览，点「保存外观」保留；关闭设置会还原未保存更改。

「文件预览」可设置透明图片底纹 / 纯色、动图播放，以及音视频自动播放、循环、静音和初始音量；保存后对新开的预览生效，不中断当前播放。「通用与存储」可设置关闭收进托盘和普通删除前确认；回收站永久删除仍始终确认。

PDF / PDF 兼容 AI 连续预览可按住中键横向 / 纵向拖动页面，松开停止；Ctrl＋滚轮缩放，开启「选字」后仍用左键拖选文字。AI 仍仅显示文件内已保存的 PDF 兼容页面，不解析画板外对象或未保存编辑图层。

## 单张图片设置为桌面壁纸

单张图片右键「设为桌面壁纸」。程序建立独立的显示用缓存，不改原图；透明背景合成白底、GIF 使用首帧。壁纸预览最长边为 4096 像素，不支持动态图桌面。源文件失效时先重新定位。测试使用模拟系统接口，不在测试阶段改变真实桌面。

## GitHub 参考项目

- [BeeRef](https://github.com/rbreu/beeref)：参考多图摆放、缩放和置顶的交互。项目为 GPL-3.0；Nook 不复制其源码，也不内置 Python / PyQt 运行环境。
- [Excalidraw](https://github.com/excalidraw/excalidraw)：MIT 的图片、文字和画线编辑器，可作为未来复杂编辑需求的后备方案；本版没有加入 React 编辑器或它的协作服务。
- [JSON Canvas](https://github.com/obsidianmd/jsoncanvas)：参考坐标与节点组织方式；它是格式规范，不是完整开源编辑器。
- [RichCanvas](https://github.com/mircea21S/RichCanvas)：MIT 的 WPF 画布组件，支持拖动、选择、平移与缩放，提供 .NET Framework 4.8 目标；可参考交互实现。本版未集成；其当前项目配置还引用 Newtonsoft.Json，不能仅凭 README 的简写断言没有额外依赖。
- [RectpackSharp](https://github.com/ThomasMiz/RectpackSharp)：MIT 的 C# 矩形排布组件，可参考未来自动整理图片的实现；它不是完整画布。本版未集成，也没有新增自动排布功能。
- [Microsoft WebView2Browser](https://github.com/MicrosoftEdge/WebView2Browser)：参考轻量导航和生命周期设计。本版用已有 WPF WebView2 自行实现控件，不复制 Win32 示例源码或引入第二套浏览器内核；该项目不能误标为 MIT。

未采用 tldraw SDK 或直接内置 PureRef，避免授权、运行环境与体积问题。tldraw 当前 SDK 正式使用需有效授权，不能按普通 MIT 组件直接内置。以上为官方仓库和声明核查，不表示已安装或完成这些项目的实机性能测试。
