# Nook 0.1.32 文件预览验证记录

本轮目标：Windows 桌面和资源管理器优先使用内容缩略图；没有可用预览时显示格式图标。Nook 应用图标保持独立，不强制修改默认打开方式。

## 组件与专项检查

- 原生组件检查：59 项通过，覆盖 SVG 内容、透明度、格式图标、异常输入和资源限制。
- 注册与回滚检查：122 项通过，覆盖其他软件已有处理器、用户默认选择、写入故障、并发修改和路径边界。
- Windows Shell 实际调用复核：10 项通过。使用 `SIIGBF_THUMBNAILONLY` 验证内容像素，未将图标回退计为缩略图成功。
- 用户 SVG 样例生成 256 × 157 缩略图，包含透明和不透明像素；PNG、MP4 的注册前后缩略图像素一致。
- 93 个 ICO 与许可清单完成字节校验；许可证保留原始字节。
- 安装器版本与安全回归：318 项在虚拟机通过；包含真实主程序版本匹配、旧版升级、同版冲突、降级与修复模式保护。

## 本轮边界

仅在开发虚拟机执行产品、Shell 注册与功能测试。实体电脑未安装本轮候选。

本轮新增 SVG 缩略图，保留系统及其他软件已有的图片、视频、文档预览能力。没有新增所有视频编码、PDF、PSD 或 AI 的通用缩略图解码器。含外部资源、内嵌图片、脚本、动画或超出预算的 SVG 回退到格式图标；不修改原文件。

一次 MP4 基线请求在 Nook 注册前出现 Windows 错误 `0x8004B200`；随后同视频请求及单独复核通过。原失败证据保留，不计为持续成功。

虚拟机中的首次文字 SVG 预览耗时 4813 毫秒，涉及系统字体扫描；普通 SVG 冷启动样例为 2344 毫秒，用户图形样例为 406 毫秒。这些是样例实测，不是所有电脑的性能保证。
