# 2026-11-04 新一轮体验与性能验证

本轮基于 0.1.40 / `a76716753a1ab9494f254412b7feee0d5fd99098`，只在专用 Windows 虚拟机使用合成素材和隔离配置测试。实体机 Nook、图库、贴图和浏览器未操作。当前是源码优化，未生成或发布新版本安装包；候选主程序保留原开发版本号，不覆盖线上 0.1.40。

## 本轮修改

- SVG 工作进程增加一次就绪握手，启动与实际渲染分别计时，各最多 8 秒，避免冷启动挤占渲染时间误报失败。总等待上界由约 8 秒变为约 16 秒（另有既有进程终止收尾时间）；不是缩短实际渲染耗时。256 MiB 子进程内存限制、20 MiB 输出限制、隔离渲染与外部资源过滤保留。
- 图库稀疏选择使用按需索引，避免每次读取选中素材都遍历全库；全选仍使用一次顺序扫描。返回顺序保持原图库顺序，外部修改结果列表不改变内部选择。
- 图库刷新和切换选中项时，只通知选中状态发生变化的卡片。100 张合成素材中，选择第一张产生 1 次通知，重复同步 0 次，切换到另一张 2 次，清空 1 次。
- 重新读取元数据时主动释放旧索引；同样数量、不同顺序的新快照不会返回旧对象。
- 仅启用文字识别、关闭翻译时，校正按钮提示不再承诺重新翻译。已有功能边界测试覆盖此问题。

## 失败复核

1. 看图翻页数量：测试包装程序额外放入一张参考图片导致兄弟文件数量增加。修正只为需要它的详情测试创建该图片后通过，未修改产品导航逻辑。
2. AI 预览关闭：基线出现一次 8 秒内未结束；候选代码两次生命周期复测通过。独立诊断确认关闭时读取仍在运行，随后约 187 ms 结束，原文件可独占打开且字节不变。未找到可重复的关闭泄漏，不把偶发失败涂成从未发生。
3. 插件保存与增强图像：精简 VM 包分别漏放图标样例和 image-codecs/config/policy.xml；补齐后本地桥接 123 项、增强图像并发 3 项通过。正式 .40 包存在这些文件。
4. 截图收藏测试：后台入口原先编译成不同程序集名，XAML 的 assembly=Mori 加载了另一份类型，造成类型转换失败。以 Mori 程序集身份编译测试入口后通过。
5. **已修复：SVG 冷启动导入。** 相同小型 SVG 在 2048 边长的独立进程诊断中，首次约 8.994 秒，第二次约 4.294 秒。原保护阈值为启动和渲染共用 8 秒，冷调用在约 8.2 秒被终止。分段诊断总计约 3.868 秒，XML 读取约 90 ms、SVG 打开约 1.36 秒、绘制约 705 ms、PNG 编码约 586 ms；进程/运行时冷启动存在额外耗时，具体系统原因尚未证明。改为一次受校验的就绪握手，启动和渲染分别受限；最终全新 VM 包首次执行 GeneralPerformanceTests 的 SVG 导入已通过，同组 26 项全通过。保留内存、输出和隔离保护；没有禁用系统签名校验或安全软件，也没有只依赖 512 边长测试代替首次 2048 导入。
