# Nook 0.1.39 预览版验证记录

## 改动范围

单击素材不再自动展开右侧详情栏。选择操作与浏览筛选共用原有固定工具栏行，避免改变图库的宽度或起点。详情栏仍可主动打开、收起，并保留原有宽度；选择与取消选择继续更新详情内容。多选入口保留当前选择，取消可退出空的多选模式。

## 验证方法

使用专用 Windows 虚拟机、合成素材和隔离配置。对真实 WPF 主窗口离屏布局，比较选择前后图库边界、滚动偏移和可见缩略图矩形；覆盖 1040 / 1366 宽度、深浅主题、网格 / 瀑布流、详情栏开关、顶部 / 已滚动位置，以及单选、换图、Ctrl 多选、连续点选、全选和取消。测量时执行真实延迟重排路径，防止只在重排发生前检查。

同时检查选中操作的尺寸、实际命中范围及重叠，以及主页导航、分类、多选操作、详情草稿和浏览设置的相关回归。

此记录在封包前写入。精确发布包的最终结果在同路径 GitHub 文档追加，不为回填结果而改写已核验的发布附件。
