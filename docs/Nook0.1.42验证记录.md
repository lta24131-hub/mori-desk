# Nook 0.1.42 预览版验证记录

本轮改进浏览器收藏的桌面通知。主程序与安装器 0.1.42.0，随附插件 0.2.31。运行检查均在专用 Windows 虚拟机、隔离配置及合成素材中完成。

## 使用变化

- 收藏中显示紫色状态标志和动态进度条；成功显示绿色大勾及“收藏成功”，提供查看图库入口。
- 成功结果停留 4 秒，鼠标悬停或键盘焦点位于卡片内时暂停计时。网页备用通知采用相同时间。
- 首次通知按前台窗口所在屏幕定位到右下角；同次收藏的结果保留在原屏幕，不随切换软件跳到其他屏幕。
- 关闭正在收藏的提示只隐藏进度，真正完成时仍显示结果；关闭已经完成的结果后不再弹出。
- 不显示虚构的百分比；保存迟迟未确认时不会误报成功。每个屏幕同时最多三张通知卡片。
