# Test fixtures

`cube.step` is the public cube-fcstd sample from occt-import-js (`test/testfiles/cube-fcstd/cube.step`), used to verify the bundled STEP parser. It is not a user's CAD drawing. Upstream: https://github.com/kovacsv/occt-import-js . The importer's license is included in `web/model/occt`.

`tetrahedron.stl` is a synthetic tetrahedron generated for viewer smoke testing. Tests create their own isolated databases and images. Generated screenshots, test libraries, and local test output are not published.
