# Nook 安装和使用说明

本说明对应 **Nook 0.1.33.0 预览版**，随附浏览器插件为 **0.2.27**，发布标签为 **`v0.1.33-preview`**，新增下文「Windows 文件图标与缩略图」。以发布页实际资产为准。0.1.30、0.1.31、0.1.32 是中间候选，不需先安装它们。历史版本的菜单与功能可能不同。

本版优先保留 Windows 内容缩略图，新增 SVG 预览和 Nook 关联文件的格式图标；沿用更新替换、旧程序清理、固定启动入口、真实数据目录保护及浏览器收藏连接修复。截图、画布、转换与原有预览能力保留。**并非全部功能都已验收通过：真实跨窗口拖拽、WEBM 缩略图、部分 SVG 和密集小字 OCR 仍需继续改善。** 具体范围见「Nook0.1.33发布说明.txt」及「Nook0.1.33验证记录.md」，转换见「Nook格式转换试用说明.txt」，截图操作见「Nook滚动截屏使用说明.txt」。0.1.23 及更早版本没有主程序更新入口，首次需手动下载安装本版。

独立下载的 Nook-Guide.txt 为本次校正后的说明。为保留已经实际安装验证的二进制和压缩包，安装器及便携包未重新打包；包内部分候选说明可能仍提及旧版本，以本说明及发布页为准。

安装包只含软件和使用说明，不含旧电脑的素材、贴图、设置或账号凭据；换电脑首次打开空图库是正常的。安装与数据迁移是两步，已有内容请按第八节分别迁移。

原有项目画板缩略图、明确选择加入目标的画布流程、截图标注及双屏基础功能保留。旧版实测记录不能替代本轮新功能验收，也不代表所有电脑、键盘操作、不同缩放比例或文件格式均可用。滚动截屏增加独立按需运行的组件及运行时；本版不附个人图库、缓存或可选语言包。

## 一 下载和安装

### 本版本下载：Nook 0.1.33

1. 在新电脑打开浏览器，无需 GitHub 账号。
2. 打开 <https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.33-preview>，以实际资产为准。仓库已公开，发布后的下载无需登录。
3. 展开页面下方的 **Assets**，下载 **Nook-Setup.exe**；可另存 **Nook-Guide.txt**，并按 **SHA256SUMS.txt** 核对下载文件。`Source code (zip)` 和 `Source code (tar.gz)` 是源码，不是安装包。
4. 双击安装包，确认安装提示。通常不需要管理员权限。安装完成后，打开桌面或开始菜单里的 **Nook**。
5. 首次打开空图库是正常的；软件不会自动同步旧电脑的内容。

也可以下载 `Nook-0.1.33.0-portable.zip`，完整解压到一个长期保留的文件夹，再双击 `Mori.exe`。不要在压缩包内直接运行，也不要只复制一个 EXE。便携版只代表不用安装，默认数据仍写入用户数据目录，不会自动存在 ZIP 旁边；升级时手动下载、退出后换用完整新目录，不覆盖正在运行的程序。便携版不注册 Windows 文件图标及 SVG 缩略图组件。保留 `Mori.exe` 文件名是兼容已有路由，不是另一个软件。

### 已有集合软件时更新

先备份整个图库并保存正在编辑的信息，再通过“更多”或托盘菜单完全退出（右上角 × 只会收进托盘）。旧版选 **退出 Mori Desk**，Nook 新版选 **退出 Nook**，之后运行已确认的新安装包。安装器使用固定启动入口，内部先验证新程序再切换；沿用 `%LOCALAPPDATA%\MoriDesk` 数据目录、实际选择的图库及 `app.mori.desk` 连接，保留贴图、设置和本机配对。新主窗口确认健康后清理已核对身份的旧程序；混有用户内容、未知文件或仍占用的目录会保留并提示，不按名字盲目删除。

本轮随附插件为 **0.2.27**。进入 **设置 → 浏览器收藏 → 安装 / 修复或一键更新** 检查实际副本并等待确认；扩展身份和原偏好保留，首次安装仍按浏览器提示确认。随包文件版本不等于浏览器实际加载版本，以连接回执为准。换电脑请重新注册配对，不照搬旧电脑的连接密钥。安装器拒绝降级或用不同内容覆盖相同版本；本次 0.1.33 安装包可直接升级更早版本。

安装含本功能的版本后，可到 **设置 → 关于与更新 → 检查更新** 主动查询 GitHub；打开设置本身不会联网。默认包含预览版，可取消勾选后只查正式版。正式安装目录有新版时显示说明和大小，再由你决定是否下载并重启；便携版及其他非受管理位置提供手动更新指引，不进入自动安装。下载可以取消，并核对大小与 SHA-256；正常保存、完成元数据备份并退出后才切换。新主窗口返回与本次进程匹配的启动确认后才标记成功并清理已核对的旧程序；失败时保留旧版并尝试恢复入口，不强制结束进程。元数据快照不含全部素材或贴图原图，不能代替完整备份。虚拟机已完成替换安装验证；GitHub 下载到自动安装交接的完整在线流程和所有电脑上的升级仍未全面验收。

主题在 **设置 → 外观** 选择“浅色”或“深色”，并选择紫、蓝、青、琥珀、玫瑰、灰六种强调色，共 12 种组合。底色保持白色或中性黑灰，强调色只用于选中、焦点和少量重点操作；即时预览后点“保存外观”保留，关闭设置会还原未保存更改。截图前的自动识别框会优先较大的内容区域；用滚轮向内可选择小按钮，向外可选择父框，按住Ctrl可临时忽略自动框并手动拖选。不会改变原截图、标注和素材颜色。

左侧 **项目** 用画板缩略图管理保存的画布，单击缩略图继续编辑；关闭画布窗口不删除项目。**工具 → 自由画布** 仍保留快捷入口。收藏的网址双击在软件内快速浏览，「返回收藏」回到原列表，右键仍可用外部浏览器打开。画布图片有独立附件，现有图库备份不含画布，搬迁方法见第八节。

### 项目、加入画布和绘图

1. 点击左侧 **项目 → 新建画布**，创建一个独立项目；已有项目以画板缩略图显示。也可把图片拖到具体项目卡片上加入。只拖到左侧“项目”入口还不算完成，请继续移到目标画板上再松开。
2. 在图片列表按 Ctrl / Shift 多选，再点右侧 **画布**，或右键 **加入自由画布…**。选择窗口会让你 **新建画布**，或明确选择一个 **已有画布**；不会擅自加入最近项目。原素材仍留在素材库，同一图片可以加入多个画布。取消选择不会添加。
3. 每次添加最多 **200 张图片**；项目没有四张图片的限制，但总规模仍受电脑资源和文件大小限制。视频、文件夹、网址和普通文档不是这个图片加入入口的目标，文件夹不会展开导入。画布窗口的“添加图片”按钮和直接拖入图片也可使用。
4. 使用画笔、直线、箭头、几何形状、文字等工具；选中对象后，属性面板显示适用的颜色、填充、实线 / 虚线 / 点线 / 手绘、粗细或字体等选项。箭头可拖端点和中间控制点调节方向、弯曲，并调整两端样式；不是只能修改下一次绘制的对象。
5. 使用选择工具单击或框选，Shift 加选；选中图片可拖动、缩放和旋转。选择至少两个可编辑对象时，属性面板出现对齐按钮；至少三个时还可等距排列。锁定对象不参与这些调整。
6. **按住中键**或**空格加左键拖动**平移画布，**Alt+滚轮缩放**；普通滚轮平移，Shift+滚轮横向平移。Ctrl+滚轮不再作为画布缩放。**Del** 删除所选画布对象，**Ctrl+Z** 撤销；快捷键完整列表可从画布菜单查看。
7. 编辑会自动保存；画布菜单可立即保存、重命名、复制为新画布、删除及恢复上次删除的画布。窗口最上方有 **新建、显示 / 隐藏工具、置顶**图标，鼠标停留可查看提示。隐藏工具不影响画布内容；关闭窗口会先保存，保存失败时会提示，勿强制结束程序。

画布使用独立图片副本，删除对象不删除素材库或电脑原文件；删除项目先移入可恢复的画布回收目录。SVG 和 **PDF 兼容 AI** 在画布中使用栅格预览：**AI 仅加入首个兼容页面，不是全部画板、图层或画板外对象**；普通 AI 文档预览仍可连续看其已保存的其他兼容页面。GIF 在画布中使用静态预览。此功能不是 Illustrator 或 Photoshop 的工程编辑器。

当前画布在本机加载随包附带的固定版本组件，不提供云协作、在线嵌入或自动同步。旧画布首次使用新组件打开时会转换为新记录，保留原有图片附件；若组件损坏或项目无法读取，会提示修复或重试，不以空白旧画布代替原项目。请使用完整安装包，不要仅替换 EXE。

新版确认健康启动后，会清理已核对身份且未被占用的旧程序目录；混有个人文件、未知文件或校验不符的目录保留并提示。已有自启动是否迁移，以安装方式及设置中的实际状态为准；不会因为安装而替你开启原本关闭的自启动。若需要自启动，请在新版 **设置 → 通用与存储** 核对“登录 Windows 后在托盘启动 Nook”并保存。

系统要求：Windows 10/11 x64、.NET Framework 4.8。画布、内置网址浏览、3D 和部分视频功能需要 Microsoft Edge WebView2 Runtime；截图文字识别需要 Microsoft Visual C++ 2015–2022 x64 运行库及 Windows 对应 OCR 组件。多数较新的 Windows 已有其中一些组件，但不能假定新电脑全部齐全；缺少时通过微软官方页面安装：

- .NET Framework 4.8：<https://dotnet.microsoft.com/download/dotnet-framework/net48>
- WebView2 Runtime：<https://developer.microsoft.com/microsoft-edge/webview2/>，选择 Evergreen Runtime 的 x64 版本。
- Visual C++ 运行库：<https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist>，选择当前支持的 x64 版本；不要只安装 x86。

安装包尚未代码签名。若系统或单位策略拦截，请先核对下载来源、发布页提供的 SHA-256，并保留提示信息；不要关闭杀毒或降低全局安全策略。受管理电脑可能需要管理员允许。

## 二 先分清素材库和本地文件

| 入口 | 保存什么 | 适合什么 | 原文件被移动以后 |
| --- | --- | --- | --- |
| 全部素材及图片、视频、音频 | 图库副本与符合类型的本地快捷收藏；文件夹不混入素材 | 统一查找、分类和预览 | 副本不受影响；快捷收藏仍依赖原位置 |
| 网址 | 网址、名称、来源和分类，不是离线网页快照 | 网页书签 | 打开时仍需要网站可访问 |
| 文档 | PDF 副本与本地文档快捷收藏 | 文档资料 | 副本不受影响；快捷收藏仍依赖原位置 |
| 本地收藏 | 原路径、名称和分类，不复制文件内容 | 3D 工程、任意本地文件或文件夹的快捷入口 | 需要恢复原件的位置 |

“全部素材”汇总图片（含动图）、视频、音频和模型等素材，包含本地快捷收藏；网址、文档和本地收藏有独立入口。文件夹只显示在本地收藏，不算素材。选中素材后，右侧最下面显示本地地址，并注明是“图库保存 · 独立副本”还是“快捷方式”。

本地快捷收藏占用很少的索引空间，但程序运行仍会占用内存。打开大型 3D 或图片时，也需要相应内存。

0.1.17 在文件缩略图左下角显示格式角标，例如 PDF、AI、PSD、PNG、MP4、STEP；关闭名称或详情显示后仍保留，方便区分相似预览。文件夹和网址卡片不显示文件格式角标，视频同时保留播放标识。无扩展名只标注“文件”，具体预览能力以文件内容和格式支持为准。

## 三 本地文件快捷收藏

1. 点击左侧 **本地收藏**，或直接在任意页面拖入电脑文件。
2. 拖入普通文件或文件夹默认只收藏快捷方式，不弹出导入确认。收藏文件夹只记录路径，不扫描或导入里面的内容；桌面软件提供的临时图片、网页收藏和截图则保存独立副本。
3. 本地收藏空白处右键 → **新建分类文件夹…**；把快捷收藏拖入分类文件夹整理。这是软件内的分类，不改变电脑上文件的实际位置。文件夹采用大图块，文件采用较小图块。
4. 使用上方搜索框查名称或路径；Ctrl+F 定位搜索。搜索、排序、筛选复用已加载记录。原件状态改变后可按 F5 或右键“刷新”。双击条目打开：支持的图片和 3D 使用内置查看器；其他文件交给 Windows 默认应用。0.1.15 还增加下文所列文档和媒体预览。
5. 原件改名、移动或换电脑后，快捷收藏可能失效。它不是文件备份，换电脑时需一并迁移原件。图库整体迁移保留快捷地址，但不复制这些外部原件。

Ctrl / Shift 多选，Ctrl+A 全选；右键可以批量改分类或移除收藏。Delete 仅移除引用，**不会删除电脑上的原文件**；Ctrl+Z 可撤销本地收藏当前会话最近的可恢复操作。分类删除后，里面的收藏转入未分类，不删除原件。

0.1.15：原文件移动、改名、删除或磁盘暂不可用时，双击会显示原地址，并提供“保留收藏 / 重新定位 / 仅移除收藏”。知道新位置时选“重新定位”，或右键“重新定位原文件…”；分类、标签和备注会保留，Ctrl+Z 可撤销地址修改。文件夹重新定位不会导入里面的内容。“仅移除收藏”不删除原件，也可撤销；取消不会丢弃正在编辑的备注。不知道原件在哪时先保留收藏，软件不会自动扫描其他磁盘。

## 四 素材库和网址

- 用 **导入素材** 保存独立副本。普通电脑文件拖入或文件粘贴默认是本地快捷收藏；图片内容粘贴、浏览器收藏与截图收藏保存独立副本。
- Ctrl / Shift 多选后可批量分类、导出或移入回收站。永久删除回收站内容会再次确认，确认后不能依赖 Ctrl+Z 找回。
- 双击图片预览；Ctrl+滚轮调整图库缩略图大小。左右栏分隔线可拖动。本版的默认页面、排序、缩略图布局与左右栏显示 / 宽度统一在 **设置 → 素材浏览** 调整。
- **网址**页面单独管理书签及文件夹；使用 **收藏网址** 或 **导入书签**。
- **更多 → 导入 → Eagle 图库…** 可迁移 Eagle 素材，先备份、先少量测试。不要把新版直接指向正在使用的旧 Mori 图库来测试。
- 编辑右侧信息时，搜索、筛选和外部收藏引起的列表刷新会暂缓，防止草稿丢失。点“保存信息”后继续刷新；切换选择或页面时可选择保存、放弃或取消。

## 五 截图和翻译

### 截图及原位翻译

1. 点 **工具 → 截图 / 标注 / 原位翻译**，或按默认快捷键 **F1**。
2. 拖动框选区域，在工具条选择矩形、椭圆、箭头 / 直线、画笔、文字、识别或翻译等功能。鼠标悬停可查看按钮提示；颜色、字号、粗细等只显示当前工具适用的选项。收藏按钮使用图标，提示为 **收藏到素材库（保存副本）**。
3. **原位翻译**在图像中呈现译文；**识别文字**可查看识别文本、选取需要的部分，再复制或翻译。
4. 可保存图片、复制、贴到屏幕，或点 **收藏到素材库（保存副本）**。**按一次 Esc 直接退出整次截图**，包括文字输入、绘制、菜单与识别 / 翻译状态；双屏的截图层一起关闭。系统“另存为”对话框的 Esc 按系统约定取消选路径，返回截图，不丢弃结果。工具条 × 也可退出，右键仍逐步取消当前操作或清除选区。空白选区内部双击可完成，双击标注或控制点不会误作输出。已明确提交到素材库的保存可能继续完成，Esc 不承诺撤销已提交的磁盘写入。
5. 默认 **F3** 用于粘贴 / 找回收起的贴图；**Shift+F3** 一键显示 / 隐藏全部活动贴图，也可用 **工具**或托盘的同名菜单。隐藏不是删除，也不是逐张收起。正常退出会保存活动贴图的位置、大小、透明度和方向，再次启动可恢复；逐张收起的贴图需用 F3 找回。若快捷键冲突，以设置中实际保存的按键为准。

标注快捷键：**V** 选择、**R** 矩形、**O** 椭圆、**A** 箭头、**L** 直线、**P** 画笔、**T** 文字、**M** 马赛克；**Ctrl+Z** 撤销，**Ctrl+Shift+Z / Ctrl+Y** 重做。输入文字时按键用于正常打字，不会误切工具。旧标注可直接重新选中和移动，双击文字可再次编辑；文字字号与画笔粗细分开，普通滚轮不意外修改标注。方向键微调选区，Shift+方向键调整右 / 下边，Ctrl 加速，边界会保护已有标注。使用任意绘图工具时，也可直接拖动选区四边或四角，靠近时显示相应缩放光标；调整后保留当前工具，并支持撤销 / 重做，不再需要工具条的“选择 / 调整”按钮。

### 滚动截屏

1. 在一块显示器内框选实际滚动内容，点击截图工具条的 **滚动截屏** 图标。
2. 选区旁显示纯图片预览，下方固定显示 **编辑、保存、取消、完成** 四个图标。把鼠标放在原选区内滚动原页面；预览不跟随鼠标，滚轮不调画笔。
3. 预览随长图增长，在可用屏幕空间内等比显示完整结果；默认贴近选区右侧，空间不足时调整位置，不要求先进入编辑器。

5. 点 **取消** 或按一次 **Esc** 结束整次截图，即使目标应用已取得焦点。系统保存对话框中 Esc 只取消选路径、回到结果；取消保存或输出失败保留结果方便重试。此前已明确提交的收藏仍可能在后台完成。

请保持窗口大小、选区和页面缩放不变，缓慢沿同一方向滚动，相邻画面保留约 20% 的重叠。动画、视频、重复图案、快速跨过多屏或变化的悬浮内容可能拼接失败；以预览核对结果，不能保证每个网页都准确。单次上限为 6400 万像素、任一边 32768 像素；到达后明确提示并保留已拼接部分，由你确认后输出，再分段继续。组件失败时恢复原截图与标注。滚动组件只在本机处理，不上传页面内容。相同功能候选已有单次真实滚动与用户试用反馈，本版后台结果及未覆盖的混合 DPI、HDR、完整原生保存流程等边界见发布说明。

### Windows 文件图标与缩略图（0.1.33 新增）

资源管理器和桌面能显示图片、视频等内容缩略图时优先显示缩略图；关联为由 Nook 打开的文件无法预览时，使用写有 PNG、SVG、PDF 等格式的文件图标，其他默认应用保留原图标。小图标模式显示对应类别符号。Nook 的程序、快捷方式和「打开方式」应用标志不变。

熟悉命令行的用户仍可在程序目录运行 `Register-Extension.ps1 -ExtensionId 扩展ID`；它使用相同的连接逻辑。若单位策略禁止开发者模式或本机连接，请联系管理员，不绕过限制。

### 4 验证网页收藏

1. 打开 Nook，刷新要收藏图片的**普通网页**（浏览器设置页、新标签页等不支持注入收藏区）。
2. 点击浏览器扩展图标检查连接状态；可将 Nook 图标固定到工具栏。
3. 先右键一张普通网页图片 → **收藏到 Nook**，再测试拖拽到收藏区。
4. 回 Nook 点 **全部素材**，必要时按 F5，确认图片及来源网址已经出现。
5. 网址收藏和书签导入也由插件提供；导入书签只复制，不删除浏览器原书签。首次使用时浏览器会请求书签访问权限。

若提示“未收到收藏结果”，请先在图库确认再重试，软件不会自动重发不确定是否已保存的请求。插件会暂停自动更新，直到你在插件弹窗确认已检查之前的收藏结果。

需要登录、受限或分段流媒体的视频不保证可收藏。应先确认当前浏览器能正常播放；失败时提供网页链接和错误提示，不要把收藏网址当作已下载视频。

### 5 一键更新

安装新版 Nook 后，进入 **设置 → 浏览器收藏 → 一键更新**。更新只使用当前软件随附的插件文件，不从陌生网址下载代码。

- 浏览器和 Nook 都保持运行。通常会在下一次检查时处理，可能需要约半分钟。
- 正在拖拽、编辑、选择重复项、保存或导入书签时会等待；插件弹窗打开时也会等待，完成操作后关闭弹窗即可。
- 同一插件目录在多个浏览器或用户配置中使用时，先保留一个浏览器，等其他连接过期后再更新。
- 文件更新后会自动重新加载并恢复普通网页上的收藏功能。只有收到新插件的连接确认，设置页才显示运行的新版本。
- 更新失败会保留原目录或恢复副本，不会清空图库、分类或浏览器偏好。若仍未连上，点 **安装 / 修复**，不要删除图库。

这是浏览器插件的本地更新，与 **设置 → 关于与更新** 中的主程序更新分开。本轮随附 0.2.27，以浏览器实际更新确认和连接状态为准。首次安装和浏览器要求的新权限确认仍需人工完成。受单位管理的浏览器可能禁止加载扩展，请联系管理员，不绕过限制。

### 格式转换：保留原件，点格式即转

素材库文件：**右键 → 转为 → 目标格式**。常用目标最多五项，其他目标在“更多格式”；转换生成新副本加入当前图库，原文件保留，转换时仍可浏览其他素材。

外部文件：**工具 → 格式转换 → 拖入文件 → 点格式**。无需先收藏，结果保存到“设置 → 通用与存储 → 转换结果保存位置”。关闭小窗只是收起，不中断正在进行的任务。

图片／基础 PDF 核心随包提供。视频、音频、Office 等缺少引擎时，按提示进入 **设置 → 转换组件** 安装需要的组件；同一页面可以更新和卸载，不自动下载全部引擎。不是任意文件都能互转。详见随包「Nook格式转换试用说明.txt」中的格式、图层、音轨、排版及容量限制。

设置按功能分组，不再把外观和全部浏览偏好挤在通用页面里；本版新增「关于与更新」：

| 分组 | 可调整内容 |

| 通用与存储 | 图库位置 / 整体迁移、转换结果保存位置、登录 Windows 后托盘启动、关闭收进托盘、移到回收站 / 移除快捷收藏前确认 |
| 外观 | 浅色 / 深色与六种强调色，预览、保存、恢复默认、还原未保存更改 |
| 素材浏览 | 默认打开页面、排序、缩略图布局 / 大小、名称 / 详情、左右栏显示和宽度 |
| 文件预览 | 透明图片背景、动图播放、音视频默认播放 / 循环 / 静音 / 音量、网址打开方式 |
| 截图与翻译 | 13 项截图工具选配、基础 / 全开预设、长图快速启动、快捷键、翻译服务、识别语言与可选包 |

| 浏览器收藏 | 安装 / 修复、连接检查和插件一键更新 |
| 转换组件 | 按用途检查、安装、更新和卸载额外转换引擎，显示下载大小和磁盘占用 |
| 关于与更新 | 当前版本、主动检查 GitHub、是否包含预览版、更新说明、下载 / 取消与确认重启更新 |

各组使用本页的保存 / 应用按钮，不是点一次通用“保存设置”就保存所有页面。恢复默认后也需保存；测试窗口不会写入个人设置。外观即时预览，关闭设置会还原未保存的外观；其他选项按各页提示生效。

**通用与存储** 默认不开启 Windows 自启动；主窗口默认关闭收进托盘。取消“关闭主窗口时收进托盘”并保存后，× 改为正常退出。开启“移到回收站 / 移除快捷收藏前确认”可减少误操作；回收站里的永久删除始终会确认，不能关闭这层保护。图库位置改变时会复制并校验后再切换，原图库保留。

**文件预览** 的透明背景有自动底纹、浅色底纹、深色底纹、纯白、深灰，均只影响显示，不写进原图。默认播放动图；音视频默认自动播放、循环、非静音、初始音量 70%。可分别修改，保存后对新打开的预览生效，不打断当前播放。网址默认内置快速浏览；关闭后双击或选中后按空格均使用默认浏览器，右键仍保留两种打开方式。

**自由画布** 默认新项目不置顶；自动保存为停止编辑后 1.2 秒，可设为 0.5–10 秒。可设新项目是否显示网格和工具栏、图形吸附、0.5–2 倍缩放速度，以及实线 / 虚线 / 点线 / 手绘、默认大小；默认大小影响新绘图形的线宽和文字大小，不改动已有内容。保存后下次打开画布生效，已有项目保留自身的置顶、网格与工具栏状态，关闭时仍会保存。折叠的“旧版画布缓存”默认 48 MiB，可设为 16–128 MiB（界面标为 MB），**仅用于旧版画布**，不限制当前画布或整个软件内存，也不是项目数量上限。

从桌面软件拖图片到 Nook：支持常见图片数据、单张虚拟图片、临时图片和可访问的图片链接。接收到图片数据时保存图库副本，来源软件关闭也不会丢失；普通电脑文件继续只记本地地址。单张限制 20 MB。若来源软件只传出需登录的图片链接或没有图片数据，请在来源软件右键“复制图片”，再到 Nook 按 Ctrl+V；也可先保存图片到电脑。浏览器插件不负责 GPT 桌面软件的拖入。

Nook 为兼容升级，默认程序仍位于 `%LOCALAPPDATA%\Programs\MoriDesk` 下的版本文件夹，默认数据仍位于 `%LOCALAPPDATA%\MoriDesk`；改名不会迁走或清空现有数据。这些路径可以粘贴到文件资源管理器的地址栏打开。

- `Library`：默认图库。若你已更改保存位置，以 **更多 → 图库管理 → 打开图库文件夹** 显示的实际位置为准。
- `capture`：截图翻译设置、贴图记录和可选包。图库备份不自动包含它。
- `free-canvas`：画布布局与独立图片附件。图库备份不包含它；需要单独迁移。
- `browser`：当前电脑的浏览器连接配置，换电脑应重新注册，不要照搬。

### 只想在另一台电脑测试

下载安装即可，使用新空图库。不需要把旧电脑整个目录复制过去，也不需要登录翻译服务账号。

### 以后要搬迁 Nook / Mori Desk 的集合软件数据

1. 在旧电脑保存正在编辑的信息和画布，选择 **更多 → 图库管理 → 备份整个图库…**，产生 `.mori.zip` 文件。先保留原图库和备份，不删除原件。
2. 在新电脑安装本次版本并检查运行时。将 `.mori.zip` 复制过去，打开 Nook，选择 **更多 → 图库管理 → 从备份恢复到新文件夹…**，使用一个空文件夹；随后用 **选择 / 创建另一个图库…** 打开恢复目录。
3. 图库副本、网址、分类及本地快捷收藏记录随备份恢复；**快捷收藏引用的原文件不在备份中**。另行搬迁这些文件，在 **本地收藏** 中用 **重新定位原文件…** 修复地址。保持原盘符和路径可减少修复工作；收藏文件夹不会递归导入原件。
4. 两台电脑都完全退出 Nook / Mori Desk，再分别备份旧电脑数据目录中的 **`capture`** 和 **完整 `free-canvas`** 目录。旧版菜单为 **退出 Mori Desk**，新版为 **退出 Nook**；右上角 × 通常仅收进托盘，不等于退出。
5. 贴图和翻译设置需要 `capture`，画布需要 `free-canvas` 中的项目记录和全部图片附件。将所需目录复制到新电脑数据目录的同名位置；新电脑已有内容时先备份，**不要直接覆盖**。本版没有贴图或画布目录的自动合并工具。`.mori.zip` 不含这两个目录，不能只复制画布 `project.json`。画布中已保存的图片有独立附件，不依赖旧电脑的原图片路径继续显示。
6. 新电脑启动后检查图库、分类、贴图和画布各一项，再通过 **设置 → 浏览器收藏 → 安装 / 修复** 完成新电脑配对和浏览器首次加载。**不要复制旧电脑的 `browser`、`local-key.txt`、`local-connection.js` 或整份已配对插件目录**；软件包自带无配对密钥的插件。需要自启动时，在新电脑设置中重新勾选并保存。

独立旧 Mori 和 Luma 与集合软件 Nook / Mori Desk 的数据目录不同。本版不自动迁移或删除它们；先测试满意，再安排备份迁移。不要把正在使用的图库放在两台电脑的云盘同步目录里同时读写，本版不是多机同步工具。

## 九 常见问题

- **GitHub 页面 404**：仓库已公开，请检查网址、发布标签及网络；无需登录私人账号。
- **程序不能启动**：确认是 Windows x64、完整解压，检查 .NET Framework 4.8；不要仅复制 EXE。
- **画布 / 网址浏览 / 3D / 视频白屏或缺少运行时**：检查完整解压及 WebView2 Runtime，安装后重开对应窗口；提供错误截图。画布无法载入时可以关闭，不要删项目目录或用空白记录覆盖原项目。
- **中文或其他语言识别失败**：检查 Windows 对应 OCR 组件、软件识别语言是否启用、可选包是否下载完成。英文已有内置模型。
- **翻译失败**：确认所选服务及网络；Google 需要可达网络，离线服务需先装包。软件不保证第三方在线接口永久可用。
- **插件未连接**：先打开 Nook，在 **设置 → 浏览器收藏** 点击 **安装 / 修复**，按提示完成首次加载或旧版首次重载，再验证普通网页收藏。新版插件在原本机连接不可用时可自动使用已配对的备用通道，要求 Nook 正在运行（收进托盘也可以）。它仅在本机通信，不上传素材。`browser/local-key.txt` 和插件目录中的 `local-connection.js` 是本机配对密钥，不要分享；换电脑请重新连接。
- **网址小图标反复加载**：图库地址过长时，Windows 的路径长度限制可能导致图标缓存无法保存。建议选择较短的图库路径；这不影响网址记录本身。
- **关闭窗口后仍运行**：默认收进托盘。新版右键系统托盘图标 → **退出 Nook** 可完全退出；旧版菜单为“退出 Mori Desk”。本版也可在“通用与存储”取消关闭收进托盘。独立图片 / 3D 窗口需各自关闭，画布在完全退出前保存。
- **更新怎么办**：本说明对应 `v0.1.33-preview`，以第一节所列发布页实际资产为准。0.1.23 及更早版本需先备份并完全退出，再手动安装一次本版；之后可在 **设置 → 关于与更新** 操作。自动安装只用于正式安装目录；便携版按提示手动换用完整新目录。浏览器插件目标版本为 0.2.27；需升级时在 **设置 → 浏览器收藏** 中操作，首次仍可能需要浏览器确认。
- **想删除测试版**：当前没有完整卸载器。先在设置关闭自启动、完全退出并移除该集合软件的浏览器插件，再删除明确属于 Nook / Mori Desk 的程序版本目录和快捷方式。数据目录先保留，确认不需要后再自行处理；不要删除独立旧 Mori / Luma 的目录。
