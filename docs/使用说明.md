# Mori Desk 安装和使用说明

适用于 Mori Desk 0.1.12 预览版，随附浏览器插件 0.2.18。你可以在另一台 Windows 电脑安装，先用几份不重要的文件测试。安装包只含软件，不含旧电脑的素材、贴图、设置或账号凭据。

## 一 下载和安装

1. 在新电脑的浏览器登录 `lta24131-hub`，或其他被授予此私有仓库访问权限的账号。
2. 打开 <https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.12-preview>。
3. 展开页面下方的 **Assets**，下载 **Mori-Desk-Setup.exe**。`Source code (zip)` 和 `Source code (tar.gz)` 是源码，不是安装包。
4. 双击安装包，确认安装提示。通常不需要管理员权限。安装完成后，打开桌面或开始菜单里的 **Mori Desk**。
5. 首次打开空图库是正常的；软件不会自动同步旧电脑的内容。

也可以下载 `Mori-Desk-0.1.12.0-portable.zip`，完整解压到一个长期保留的文件夹，再双击 `Mori.exe`。不要在压缩包内直接运行，也不要只复制一个 EXE。便携版只代表不用安装，默认数据仍写入用户数据目录，不会自动存在 ZIP 旁边。

### 已有 Mori Desk 时更新

先备份整个图库并保存正在编辑的信息，通过 **更多 → 退出 Mori Desk** 或托盘菜单完全退出（右上角 × 只会收进托盘），再运行新安装包。安装器创建新版本程序目录，更新桌面与开始菜单快捷方式，保留数据目录；不会清空图库。安装后在 **设置 → 浏览器收藏 → 一键更新** 等待浏览器确认插件版本 0.2.18，旧插件首次升级按提示手动重载一次。

安装器不会删除旧程序目录。若曾开启自启动，请在新版 **设置 → 通用** 重新勾选“开机自动启动”并保存，使启动路径指向新版；旧路径对应的选项可能显示为未勾选。原位更新过的电脑也可继续使用当前已验证安装；没有必要仅为下载安装包再次安装。

系统要求：Windows 10/11 x64、.NET Framework 4.8。3D 和部分视频功能需要 Microsoft Edge WebView2 Runtime。多数较新的 Windows 已有这些组件；缺少时通过微软官方页面安装：

- .NET Framework 4.8：<https://dotnet.microsoft.com/download/dotnet-framework/net48>
- WebView2 Runtime：<https://developer.microsoft.com/microsoft-edge/webview2/>，选择 Evergreen Runtime 的 x64 版本。

安装包尚未代码签名。若系统或单位策略拦截，请先核对下载来源、发布页提供的 SHA-256，并保留提示信息；不要关闭杀毒或降低全局安全策略。受管理电脑可能需要管理员允许。

## 二 先分清素材库和本地文件

| 入口 | 保存什么 | 适合什么 | 原文件被移动以后 |
| --- | --- | --- | --- |
| 全部素材及图片、视频、音频 | 图库副本与符合类型的本地快捷收藏；文件夹不混入素材 | 统一查找、分类和预览 | 副本不受影响；快捷收藏仍依赖原位置 |
| 网址 | 网址、名称、来源和分类，不是离线网页快照 | 网页书签 | 打开时仍需要网站可访问 |
| 文档 | PDF 副本与本地文档快捷收藏 | 文档资料 | 副本不受影响；快捷收藏仍依赖原位置 |
| 本地收藏 | 原路径、名称和分类，不复制文件内容 | 3D 工程、任意本地文件或文件夹的快捷入口 | 需要恢复原件的位置 |

“全部素材”汇总图片（含动图）、视频、音频和模型等素材，包含本地快捷收藏；网址、文档和本地收藏有独立入口。文件夹只显示在本地收藏，不算素材。选中素材后，右侧最下面显示本地地址，并注明是“图库保存 · 独立副本”还是“快捷方式”。

本地快捷收藏占用很少的索引空间，但程序运行仍会占用内存。打开大型 3D 或图片时，也需要相应内存。

## 三 本地文件快捷收藏

1. 点击左侧 **本地收藏**，或直接在任意页面拖入电脑文件。
2. 拖入普通文件或文件夹默认只收藏快捷方式，不弹出导入确认。收藏文件夹只记录路径，不扫描或导入里面的内容；桌面软件提供的临时图片、网页收藏和截图则保存独立副本。
3. 本地收藏空白处右键 → **新建分类文件夹…**；把快捷收藏拖入分类文件夹整理。这是软件内的分类，不改变电脑上文件的实际位置。文件夹采用大图块，文件采用较小图块。
4. 使用上方搜索框查名称或路径；Ctrl+F 定位搜索。搜索、排序、筛选复用已加载记录。原件状态改变后可按 F5 或右键“刷新”。双击条目打开：支持的图片和 3D 使用内置查看器；其他文件交给 Windows 默认应用。
5. 原件改名、移动或换电脑后，快捷收藏可能失效。它不是文件备份，换电脑时需一并迁移原件。图库整体迁移保留快捷地址，但不复制这些外部原件。

Ctrl / Shift 多选，Ctrl+A 全选；右键可以批量改分类或移除收藏。Delete 仅移除引用，**不会删除电脑上的原文件**；Ctrl+Z 可撤销本地收藏当前会话最近的可恢复操作。分类删除后，里面的收藏转入未分类，不删除原件。

## 四 素材库和网址

- 用 **导入素材** 保存独立副本。普通电脑文件拖入或文件粘贴默认是本地快捷收藏；图片内容粘贴、浏览器收藏与截图收藏保存独立副本。
- Ctrl / Shift 多选后可批量分类、导出或移入回收站。永久删除回收站内容会再次确认，确认后不能依赖 Ctrl+Z 找回。
- 双击图片预览；Ctrl+滚轮调整图库缩略图大小。左右栏分隔线可拖动。
- **网址**页面单独管理书签及文件夹；使用 **收藏网址** 或 **导入书签**。
- **更多 → 导入 → Eagle 图库…** 可迁移 Eagle 素材，先备份、先少量测试。不要把新版直接指向正在使用的旧 Mori 图库来测试。
- 编辑右侧信息时，搜索、筛选和外部收藏引起的列表刷新会暂缓，防止草稿丢失。点“保存信息”后继续刷新；切换选择或页面时可选择保存、放弃或取消。

## 五 截图和翻译

### 截图及原位翻译

1. 点 **工具 → 截图 / 标注 / 原位翻译**，或按默认快捷键 **F1**。
2. 拖动框选区域，在工具条选择矩形、箭头 / 直线、画笔、文字、识别或翻译等功能。鼠标悬停可查看按钮提示。
3. **原位翻译**在图像中呈现译文；**识别文字**可查看识别文本、选取需要的部分，再复制或翻译。
4. 可保存图片、复制、贴到屏幕，或点 **收藏到素材库（保存副本）**。取消当前截图用 Esc 或工具条的 ×。
5. 默认 **F3** 用于粘贴 / 找回贴图；贴图状态会保存，正常退出后再次启动可恢复未收起的贴图。

### 输入翻译

点 **工具 → 输入翻译**，输入文字并选择翻译方向，支持中译英和英译中。默认快捷键为 **Ctrl+Alt+T**。

### 服务和语言包

打开 **设置 → 截图与翻译** 标签（在同一窗口内显示）：

- **腾讯翻译**：默认服务，适合国内网络。在线接口可能限流或变化，不保证任何网络下都可用。
- **Google 翻译**：需要电脑能访问 Google，使用现有系统网络 / 代理；软件不会自行安装代理或修改线路。
- **离线翻译**：先下载可选中英离线包，再选择离线服务并应用。下载需联网且会增加空间占用；安装完成后中英翻译在本机进行，不会自动改用联网服务。
- **识别语言包**和**翻译服务**不是一回事。识别语言包用于从图片中读取文字；英文模型随包提供，其他语言按需下载，可多选启用、更新、卸载。Windows 中文识别需系统相应 OCR 组件。

在线翻译将识别或输入的**文字**发给所选服务，不上传整张截图；涉密内容请使用离线功能或不要提交。图片本身的识别在本机完成。

同时打开不同图库时，截图快捷键、贴图和翻译由先启动的 Mori Desk 窗口管理，其他窗口仍可管理各自的素材。完全退出占用工具的窗口后，另一个窗口会自动接管；右上角 × 仅隐藏，不会释放占用。

若 F1 / F3 被旧 Luma、Snipaste 等占用，先用工具菜单测试；在快捷键设置里换组合键并保存。不要为了测试直接卸载旧软件。

## 六 看图和 3D

**工具 → 打开图片…（不收藏）**：选图后滚轮缩放、拖动查看细节；左右键切换同文件夹图片，双击或 Esc 关闭。支持 GIF 和 SVG；部分图片编码仍依赖 Windows 可用解码器。单独看图不会自动加入图库。先显示当前图片，再后台读取同目录列表；为控制占用，最多检查 10,000 个文件条目（不是递归扫描）。超大文件夹中未列出的图片仍可通过“打开…”直接查看。

**工具 → 打开 3D 模型…（不收藏）**：支持 STEP / STP、STL、OBJ、GLB、3MF。可旋转、缩放、切换材质和颜色、叠加结构线、调整方向、切换背景与全屏。文件在本机处理，不上传云端；大文件耗时取决于文件结构、CPU 和内存，不保证秒开。多文件 OBJ 材质资源的效果请实际验证。

3D 和独立看图按需开启独立窗口；关闭主窗口只会收进托盘，不会关掉这些窗口。不用时分别关闭以释放占用。

## 七 连接浏览器插件

只用本地文件、截图、翻译和查看器时，可以跳过这一节。插件随软件提供，不需要单独下载。本机连接名为 `app.mori.desk`。

### 1 打开连接指引

打开 **设置 → 浏览器收藏**，点 **安装 / 修复**，再展开 **首次安装说明**。新安装使用固定用户目录，不随主程序版本文件夹移动。

### 2 在浏览器加载

1. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
2. 打开 **开发者模式**，选择 **加载已解压的扩展程序**，选上一步的 **browser-extension 文件夹**，不是整个程序目录。
3. 选择设置页显示的插件文件夹。新安装会自动连接，不需要复制扩展 ID。
4. 若浏览器要求权限确认，由你确认。软件不会绕过浏览器限制，也不会修改浏览器安全策略。

### 3 旧插件首次升级

原来已在使用的旧插件尚不支持自动更新。**安装 / 修复**会在能验证原插件身份时提示首次升级：先完成收藏、关闭编辑框和其他浏览器，再确认升级。它保留原安装位置、扩展身份和偏好设置；随后只需在扩展管理页手动重新加载一次。不要重新加载其他插件。

本机备用连接要求 Mori Desk 正在运行（可以隐藏在托盘）。图库切换时会自动等待旧连接释放，恢复后会提示；收藏请求与图库切换互相保护，正在接收时请稍后再切换。

如原插件不在已知目录，或无法确认身份，不会猜测覆盖。可按首次安装流程加载固定目录版本，并停用旧插件，避免出现两个收藏框。**旧版连接与高级选项**仍保留手动 ID 连接入口。

熟悉命令行的用户仍可在程序目录运行 `Register-Extension.ps1 -ExtensionId 扩展ID`；它使用相同的连接逻辑。若单位策略禁止开发者模式或本机连接，请联系管理员，不绕过限制。

### 4 验证网页收藏

1. 打开 Mori Desk，刷新要收藏图片的**普通网页**（浏览器设置页、新标签页等不支持注入收藏区）。
2. 点击浏览器扩展图标检查连接状态；可将 Mori Desk 图标固定到工具栏。
3. 先右键一张普通网页图片 → 收藏到 Mori，再测试拖拽到收藏区。
4. 回 Mori Desk 点 **全部素材**，必要时按 F5，确认图片及来源网址已经出现。
5. 网址收藏和书签导入也由插件提供；导入书签只复制，不删除浏览器原书签。首次使用时浏览器会请求书签访问权限。

若提示“未收到收藏结果”，请先在图库确认再重试，软件不会自动重发不确定是否已保存的请求。插件会暂停自动更新，直到你在插件弹窗确认已检查之前的收藏结果。

需要登录、受限或分段流媒体的视频不保证可收藏。应先确认当前浏览器能正常播放；失败时提供网页链接和错误提示，不要把收藏网址当作已下载视频。

### 5 一键更新

安装新版 Mori 后，进入 **设置 → 浏览器收藏 → 一键更新**。更新只使用当前软件随附的插件文件，不从陌生网址下载代码。

- 浏览器和 Mori 都保持运行。通常会在下一次检查时处理，可能需要约半分钟。
- 正在拖拽、编辑、选择重复项、保存或导入书签时会等待；插件弹窗打开时也会等待，完成操作后关闭弹窗即可。
- 同一插件目录在多个浏览器或用户配置中使用时，先保留一个浏览器，等其他连接过期后再更新。
- 文件更新后会自动重新加载并恢复普通网页上的收藏功能。只有收到新插件的连接确认，设置页才显示运行的新版本。
- 更新失败会保留原目录或恢复副本，不会清空图库、分类或浏览器偏好。若仍未连上，点 **安装 / 修复**，不要删除图库。

这是浏览器插件的本地更新，不是主程序的在线自动更新。首次安装、旧版首次升级以及浏览器要求的新权限确认仍需人工完成。受单位管理的浏览器可能禁止加载扩展，请联系管理员，不绕过限制。

## 八 设置 保存位置和换电脑搬迁

**设置 → 通用** 可选择深浅色、默认图库位置、整体迁移图库，以及开机自动启动。本版默认不开启自启动。打开设置即显示这些选项，无需再打开子窗口。通用设置需点“保存设置”；快捷键与翻译服务分别点击对应的保存或应用按钮。

从桌面软件拖图片到 Mori：支持常见图片数据、单张虚拟图片、临时图片和可访问的图片链接。接收到图片数据时保存图库副本，来源软件关闭也不会丢失；普通电脑文件继续只记本地地址。单张限制 20 MB。若来源软件只传出需登录的图片链接或没有图片数据，请在来源软件右键“复制图片”，再到 Mori 按 Ctrl+V；也可先保存图片到电脑。浏览器插件不负责 GPT 桌面软件的拖入。

默认程序位于 `%LOCALAPPDATA%\Programs\MoriDesk` 下的版本文件夹；默认数据位于 `%LOCALAPPDATA%\MoriDesk`。这些路径可以粘贴到文件资源管理器的地址栏打开。

- `Library`：默认图库。若你已更改保存位置，以 **更多 → 图库管理 → 打开图库文件夹** 显示的实际位置为准。
- `capture`：截图翻译设置、贴图记录和可选包。图库备份不自动包含它。
- `browser`：当前电脑的浏览器连接配置，换电脑应重新注册，不要照搬。

### 只想在另一台电脑测试

下载安装即可，使用新空图库。不需要把旧电脑整个目录复制过去，也不需要登录翻译服务账号。

### 以后要搬迁 Mori Desk 的数据

1. 在旧电脑选择 **更多 → 图库管理 → 备份整个图库…**，产生 `.mori.zip` 文件，保留原图库。
2. 将备份文件复制到新电脑。打开新 Mori Desk，选择 **更多 → 图库管理 → 从备份恢复到新文件夹…**，选择一个空文件夹。
3. 恢复后再用 **更多 → 图库管理 → 选择 / 创建另一个图库…** 打开该恢复目录。
4. 本地快捷收藏的路径和分类随图库备份走，**被引用的原文件不在备份中**。另行搬迁这些文件，然后在“本地文件”里重新定位；保持原来的盘符和路径可减少修复工作。
5. 要搬贴图和翻译设置，先在两台电脑完全退出 Mori Desk，再单独备份旧电脑的 `capture` 目录。新电脑已有内容时不要直接覆盖，避免丢失新贴图。当前没有自动合并两台电脑贴图的功能。

原 Mori 和 Luma 与 Mori Desk 的数据目录不同。本版不自动迁移或删除它们；先测试满意，再安排备份迁移。不要把正在使用的图库放在两台电脑的云盘同步目录里同时读写，本版不是多机同步工具。

## 九 常见问题

- **GitHub 页面 404**：先确认登录的是有私有仓库权限的账号。不是任何人拿到链接都能下载。
- **程序不能启动**：确认是 Windows x64、完整解压，检查 .NET Framework 4.8；不要仅复制 EXE。
- **3D / 视频白屏或缺少运行时**：检查 WebView2 Runtime，安装后重开查看器；提供错误截图。
- **中文或其他语言识别失败**：检查 Windows 对应 OCR 组件、软件识别语言是否启用、可选包是否下载完成。英文已有内置模型。
- **翻译失败**：确认所选服务及网络；Google 需要可达网络，离线服务需先装包。软件不保证第三方在线接口永久可用。
- **插件未连接**：先打开 Mori Desk，在 **设置 → 浏览器收藏** 点击 **安装 / 修复**，按提示完成首次加载或旧版首次重载，再验证普通网页收藏。新版插件在原本机连接不可用时可自动使用已配对的备用通道，要求 Mori Desk 正在运行（收进托盘也可以）。它仅在本机通信，不上传素材。`browser/local-key.txt` 和插件目录中的 `local-connection.js` 是本机配对密钥，不要分享；换电脑请重新连接。
- **网址小图标反复加载**：图库地址过长时，Windows 的路径长度限制可能导致图标缓存无法保存。建议选择较短的图库路径；这不影响网址记录本身。
- **关闭窗口后仍运行**：这是托盘常驻。右键系统托盘图标 → **退出 Mori Desk** 才是完全退出。独立图片 / 3D 窗口需各自关闭。
- **更新怎么办**：主程序仍从同一私有仓库 Releases 下载，更新前备份并完全退出旧 Mori Desk。新版插件在 **设置 → 浏览器收藏** 中点 **一键更新**；旧版第一次升级需按提示手动重新加载一次。
- **想删除测试版**：当前没有完整卸载器。先在设置关闭自启动、完全退出并移除 Mori Desk 浏览器插件，再删除明确属于 Mori Desk 的程序版本目录和快捷方式。数据目录先保留，确认不需要后再自行处理；不要删除旧 Mori / Luma 的目录。

## 十 建议的首轮测试

按顺序测试：一张本地图片 → 一个小 STEP / STL → 一段中英输入翻译 → F1 截图标注和翻译 → 本地文件收藏分类 → 一张网页图片收藏。先不导入整个旧图库。

遇到问题时记录 Windows 版本、触发步骤、文件格式和大小、完整错误提示。只有必要时才提供文件，并避免发送保密图纸、账号或私人截图。
