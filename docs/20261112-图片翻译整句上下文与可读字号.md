# 图片翻译整句上下文与可读字号

2026-11-12。目标是继续接近微信截图翻译的自然语序与原位可读性。本轮全部运行测试在 NookTester 虚拟机完成，实体机只编辑、编译；未安装实体版、未发布 GitHub。保留其他任务的未提交修改。

## 真实对照与原因

旧图片翻译为保证品牌名原样保留，会先拆出名称，分别翻译两侧片段。用同一腾讯服务对照后确认，这会破坏语序，甚至改变意思。

| 原文片段 | 旧流程 | 新流程实际输出 |
| --- | --- | --- |
| couldn't sign in to GitHub after changing my password | 我无法登录 GitHub 在我改了密码之后 | 我更改密码后无法登录GitHub。 |
| asked OpenAI to cancel my subscription | 我问 OpenAI 我想取消订阅，但我还没有收到退款。 | 我要求OpenAI取消订阅，但我还没有收到退款。 |
| Save the file in SolidCraft before you close it | 将文件保存在 SolidCraft 再关上它 | 在关闭文件之前将其保存在SolidCraft中。 |
| Connect the camera to your MacBook before opening the app | 将相机连接到您的 MacBook 在打开App之前。 | 在打开应用程序之前将相机连接到MacBook。 |

没有硬编码这些译文。新流程先发送完整句子，再验证名称的拼写、边界、出现次数；只有名称被改写、遗漏、重复的区域使用原字面保护回退。其他成功区域不重翻。链接仍由本地精确保留，不把 URL 交给服务。独立名称与缩写标签无需联网。请求仍保留每批 40 区域、9500 字符、最多 2 个并发、取消和响应完整性验证。

图片缓存策略改为 `indexed-regions-v11-sentence-context`，避免旧的碎片译文被缓存命中。AI/UI/UX/API/CPU/GPU/PDF/USB 的既有偏好保留；不修改原始 OCR 文本。

## 原位字号

单行译文若被压到原行高的 68% 以下，在纯色背景下尝试利用右侧空白，保持左起点与原行高度。扩展有最大范围，并逐像素检查新区域；不跨过图片、图标、透明区域或邻近 OCR 框。只在字号至少增加 1.5 px 时采用。多行段落与复杂背景继续沿用原排版。

新增边界验证覆盖：无 OCR 标记的蓝色图片、同排标签及斜上方相邻标签。相邻保护区域外的像素逐一保持原样。排版缓存策略改为 `readable-overlays-v8-safe-reading-space`。
