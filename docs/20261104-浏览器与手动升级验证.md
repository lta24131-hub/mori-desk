# 浏览器收藏与手动升级验证（2026-11-04）

## 范围和版本

在专用 Windows 测试虚拟机中继续真实交互验证，未操作实体机 Nook、实体机 Chrome 或真实图库。使用已发布的 0.1.40 安装包，将虚拟机 0.1.38 升级；Chrome 在升级期间保持运行，原测试网页不刷新。

本轮新修改只涉及安装器提示顺序。真实升级使用的是已发布的 .40，**不包含本轮修复，也不包含提交 7a4a9b8 的图库/SVG 优化**。后续发布必须提升到 .41 或更高版本，不能覆盖已经发布的 .40。

## 已确认的问题与修改

手动更新原先先校验旧程序树与安装包，之后才检查旧 Nook 是否仍在运行。慢速虚拟机中用户等待约五分钟才看到退出提示，点击重试又进入完整校验。

现在对有有效安装记录、且版本确实较旧的运行中程序提前提示退出。此检查位于完整校验、安装进度窗口及替换锁之前；用户可以先完成收藏并正常退出，再点击重试。重试重新读取记录，实际安装仍执行完整身份、版本、完整性、并发和运行状态检查。相同版本、新版本或没有记录的旧安装沿用完整校验路径；提前读取的记录不能用来启动或注册程序。

安装包校验增加独立阶段文字，便于区分正在检查已有程序还是读取新安装包。
