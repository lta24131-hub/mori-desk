Windows 10/11 x64，个人非商用预览版。仓库保持私有，需要登录有访问权限的 GitHub 账号。

- **Nook-Setup.exe**：推荐，安装并创建桌面入口。

- **Nook-Guide.txt**：安装、使用及换电脑迁移步骤。
- **SHA256SUMS.txt**：下载文件校验清单。

`Source code` 是源码，不是安装程序。发布内容不含个人素材、图库、设置、贴图、浏览器配对密钥或可选语言模型。

## 这次更新

- 左侧项目显示画板缩略图；选择图片后可新建画布，或指定已有画布加入。绘图、箭头、几何形状、文字、样式调整、对齐、置顶及隐藏工具集中管理。
- 修复画布空白、保存与关闭、预览缩略图和图片资源路由；保护未保存编辑。优化主页三栏、空状态、选择状态和本地收藏信息。
- 图片可钉在桌面；贴图重启恢复，Shift+F3 一键显示 / 隐藏。改进独立看图、打开方式和 Eagle 元数据读取。
- 截图工具条分组，撤销 / 重做、文字重选编辑、选区微调及取消流程更连贯，避免绘制中误输出。
- 双屏按鼠标位置激活，不互相抢焦点；右键清除选区后可换屏重选，使用同一次冻结画面；工具栏靠边避让，退出清理整次截图，新贴图按鼠标屏幕放置。

## 安装与更新

1. 首次使用运行安装器，缺少运行时按指南从微软官方页面安装 .NET Framework 4.8、WebView2、Visual C++ x64 运行库。
2. 更新前保存编辑、备份数据，点「更多 → 退出 Nook」（右上角 × 通常只是收进托盘），然后运行安装器。旧程序和用户数据不由安装器删除，沿用原数据目录。
3. 原来启用自启动的，安装后到设置确认并保存，使路径指向新版；安装器本身不自动迁移该启动项。
4. 网页收藏：设置 → 浏览器收藏 → 安装 / 修复。首次仍需在 Chrome / Edge 手动确认加载；已有扩展可用一键更新，旧迁移版本可能还需手动重载一次。主程序安装不代表浏览器扩展已自动替换。
5. 新电脑不会自动获得旧电脑素材。按指南分别迁移图库、外部原件、贴图与完整画布目录；新电脑重新配对浏览器，不照搬本机连接密钥。
