## 行为

## 失败记录与边界

内部 0.1.32 的版本常量遗漏和 SVG 处理器误判见 [0.1.32 验证记录](Nook0.1.32验证记录.md)。0.1.33 从程序集读取安装业务版本，并仅将经过精确身份检查的 Windows 通用 image 处理器视为回退，不忽略 SVG 专用或自定义处理器。

0.1.33 首次只读验收辅助程序把不存在的注册表值转换为空字符串，导致隔离检查误报；修复辅助程序保留 null 后重测通过，产品代码未因此改变。MP4 首次调用再次出现 Windows `0x8004B200`，该现象在 Nook 注册前基线也发生；Explorer 和定向复测取得真实画面。此波动仍保留为已知限制，不宣称所有首次视频请求都成功。

本轮未新增所有视频编码、PDF、PSD、AI 的通用缩略图解码器。外部资源、脚本、内嵌位图、动画或超出预算的 SVG 回退图标；首次文字 SVG 可能较慢。系统“始终显示图标”偏好保持不变。

用户说明的关联范围和候选版本文字在包冻结后勘误，本记录在验收后补充；已实装二进制和上述包哈希未改变。实体机安装、发布及完整在线更新交接不属于本轮已完成验收范围。
