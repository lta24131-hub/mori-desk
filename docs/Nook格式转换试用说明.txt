Nook 格式转换 · 拖入即转

状态
本说明对应 0.1.26 预览版，提供统一转换入口和按需组件管理。
发布主程序使用虚拟机 c11 实测候选，完整范围见 Nook0.1.26发布说明.txt。
历史典型样例与本轮受控检查分开，不代表所有文件或编码均已测试；
组件的供应商真实下载／安装／更新／卸载仍未完成整链验收。

已验证的典型流程
— 图片、透明图片、多帧动图、多页 PDF 的转换与原件保留。
— 视频转视频、提取音频、音频转换，以及字幕格式转换。
— DOCX → DOC → PDF，检查两页内容和文字。
— XLSX → XLS → CSV，检查单元格内容。
— EPUB → AZW3、EPUB → MOBI，检查电子书结果格式。
— JSON / YAML 等数据、部分 3D，以及 ZIP / 7z 压缩格式转换。
— 素材库转换副本的分类继承，外部文件转换不自动入库。
— 取消、重复点击、收起窗口继续转换、格式检查失败重试及结果文件保留。

电脑里的文件
工具 → 格式转换，把文件拖进去，点目标格式，就开始转换。
也可以点“选择文件”。不必先导入素材库。
不选择质量和保存目录，不需要再点一次“开始”。
新文件自动保存到设置中的“转换结果保存位置”，原文件不变。
未修改设置时，初始位置仍为“文档\Nook 转换”。
完成后双击打开结果，或者复制、拖到其他软件，亦可打开所在文件夹。
关掉或按 Esc 收起小窗，不会卡住主界面，也不会中断已开始的转换。
重新打开格式转换，可以查看当前进度和本次软件运行期间的结果。
退出整个 Nook 后，已经生成的文件仍保留在该任务使用的结果目录。

保存位置
设置 → 通用与存储，分别设置“图库保存位置”和“转换结果保存位置”。
— 图库保存位置：整体复制图库并校验，成功后才切换；原图库保留在原处。
— 转换结果保存位置：只影响以后从“工具 → 格式转换”生成的新文件。
  例如可设为“D:\Nook\转换结果”；保存设置不会提前创建文件夹。
— 改转换结果位置不会移动已有结果，也不改变正在进行任务的保存位置。
— 素材库右键“转为”生成的副本仍归当前图库管理，不存进工具的结果目录。
— 两项设置彼此独立，不会更改程序、附加组件、桌面贴图或库外快捷引用的位置。
— “还原未保存更改”重新读取当前设置，不把另一个窗口已保存的新位置改回旧值。

素材库里的文件
右键素材 → 转为 → 目标格式。
首层优先显示最多五个当前可执行的常用目标，其他能力在“更多格式”。
点格式即开始，不打开复杂面板，不选择保存目录，不需要第二次确认。
原文件和原素材记录保留，不覆盖、不移动、不替换。
转换副本自动保存到当前图库，继承原分类、标签、备注和来源网址。
底部显示进度及结果；转换时仍可查看其他素材。
不会强制切换页面，也不清空当前选择。
主素材库原有的拖入收藏功能不改变；仅格式转换小窗里的拖入用于转换。

批量转换
一次拖入多个文件，或在素材库选中多项，仍然只需点目标格式。
只显示这批文件都可以转换的格式。已经是目标格式的文件会跳过。
菜单绑定当时选择的素材；选择变化后请重新打开右键菜单。
任务开始后不会因为你选了另一张图片而换掉源文件。
PDF 的页面、动图拆出的帧分别保留，结果保持页序或帧序。

格式范围
统一入口接入 Filee 的实际转换路线，包括图片、PDF、Office、文本与数据、
字幕、视频、音频、电子书，以及部分 3D 和压缩格式。
具体目标依赖文件类型和已安装的转换组件：只显示当前真正可用的路线。
不是所有文件都能互转，也不等于有后缀就保证能成功。
部分复杂文档、特殊编码、加密文件和带外部资源的文件可能无法转换。
缺组件或不支持时会说明原因，不会自行寻找电脑里的第三方程序。

第一次转换某类文件
图片、基础 PDF 等转换核心随软件提供，不必先下载所有转换引擎。
如果当前文件需要附加组件，点“安装所需组件…”：
— 页面把当前文件需要的组件排在最前，显示用途、下载大小和预计磁盘占用。
— 点“安装”才开始下载；单纯拖入文件或打开页面不会自动下载。
— 安装完成后关闭组件窗口，格式转换小窗会重新检查当前文件。
— 如果从素材库进入，重新右键素材 → 转为，即可查看新的格式。
— 点目标格式开始转换，原文件仍保留，不会因为安装完成而自动转换。
组件管理窗口不会锁住素材库；期间可以查看其他素材。
若取消安装或下载失败，原文件、已有转换结果及先前安装成功的组件版本保留。
正在使用组件转换时不能同时卸载或替换它，请等当前任务完成。

组件管理
设置 → 转换组件，可检查、安装、更新或卸载以下用途的组件：
— 视频与音频：FFmpeg。
— Office 文档：LibreOffice，连同所需的 Java 和文档兼容依赖一起安装。
— 电子书：calibre。
— 文本与文档：Pandoc。
— PostScript：Ghostscript，连同所需的运行库一起安装。
— 压缩文件：7-Zip。
— 韩文文档：rhwp。
不是每一种文件都需要这些组件；只装自己用到的即可。
共享依赖随所属组件管理，不提供单独删除依赖的入口。
“检查组件更新”检查当前 Nook 已批准的固定版本，不是任意下载第三方最新版本。
升级 Nook 后，如果它批准了新的兼容组件版本，再在这里点更新。
若组件来自较新的 Nook，旧版本不会强行降级；请先更新 Nook。
卸载只移除对应转换组件，不删除原件、素材库或已经生成的结果。
组件保存在当前 Windows 用户的独立目录，Nook 升级不会重复下载它们。
换电脑时需在新电脑按需安装；个人文件和图库另行迁移。

重要限制
— 每批最多 100 个文件，单个输入最多 8 GiB，单次结果累计最多 16 GiB。
— 不递归导入文件夹。不接受网址、网络共享、设备路径或符号链接。
— JPG 不支持透明，转换副本的透明区域变为白色；原透明图片保留。
— PSD / PSB 输出合成画面，不保留可编辑图层。
— PDF 转图片会栅格化，每页独立输出，不保留可选文字层。
— PDF 转 PPTX 以整页图片组成幻灯片，不是把图形还原成可编辑对象；PDF 转 TXT 不会自动识别扫描图片里的字。
— 动图转静态图片会拆出所有帧；不会无提示地只保留第一帧。
— 视频、音频及文档使用默认转换设置，可能有重编码或排版变化。
— 视频转视频默认保留第一路画面和第一路音频，不保留额外音轨、字幕和附件；菜单会提前说明。
— 视频转音频只提取声音，不保留画面。邮件转 ZIP 只提取附件，不包含邮件正文。
— 使用 8 位图片引擎，不保证高位深、HDR 或文件内嵌元数据无损保留。
— 依赖多个配套文件的输出暂不提供，避免产生缺纹理、缺图片的残缺结果。
— 试用阶段会保留 .mori\conversions 下的转换结果，加入图库后仍有这份暂存副本，会额外使用磁盘空间。
— 只支持实际验证的转换流程，不承诺所有文件、所有编码都能成功。

失败时
失败不会修改源文件；已完成的副本保留。
底部说明未完成的原因，不把失败提示成全部成功。
若副本已生成但暂未加入图库，结果文件仍会保留，并提示其位置。
转换期间仍可浏览素材；“更多 → 取消本次转换”可停止后续文件。
已完成的副本仍会加入素材库。切换图库、移动图库或真正退出前，请等待任务完成或取消。

运行方式
格式检查和实际转换都在独立后台组件中执行，用完即退出，不常驻。
它自带运行时，无需另装 Filee 软件或 .NET，也不接管系统右键菜单。
缺少附加组件时会提供明确安装入口，不会在后台自行安装。
隔离为独立进程旨在隔离兼容性与生命周期，不是完整的安全沙箱。
日常未使用时不会驻留额外转换进程；转换中的内存随文件变化。
按需安装的组件会增加磁盘占用，但不会随 Nook 启动全部加载进内存。
Office、电子书等组件较大，安装前会显示大小；安装更新期间还需临时下载和解包空间。
安装完成不需要重启 Nook；再次检查当前文件就能使用新启用的格式。
核心与附加组件都不接管文件关联，不替换电脑上已有的 Office 或其他软件。

开发构建
先按 modules/file-conversion/README.md 构建经过固定版本和校验验证的转换核心。
默认构建不携带全部大型引擎，运行时由用户明确选择安装经过校验的附加组件。
构建 Nook 时显式传入 -FileConversionDirectory <组件目录>，使用新的输出目录。
打包时须显式传入 -IncludeExperimentalFileConversion，脚本会验证组件完整性与许可。
未启用该选项时不会把这项试用功能混入常规发布；带组件但未声明的构建会拒绝打包。
