# Nook 0.1.37 预览版验证记录

## 本轮改动

画布滚轮默认缩放，以鼠标位置为中心；中键 / 空格拖动平移，Shift+滚轮横向平移。Alt / Ctrl+滚轮兼容保留。缩放先限制到相机允许的范围，到达上下限后继续滚动不再移动画面。空画布提示同步更新。

主程序与安装器版本提升至 0.1.37.0。浏览器插件仍为 0.2.28，启动器及附带运行组件复用 0.1.36 的已验证版本。没有修改图库、画布保存格式或更新安装流程。

## 验证范围

2026-11-03，滚轮改动提交 `d09e5c5` 在专用 Windows 虚拟机通过 `editor-mount.test.tsx` 的全部 15 项实际挂载 SDK 回归。滚轮用例从画布 DOM 派发事件，验证一次事件只缩放一次、鼠标锚点、普通 / Alt / Ctrl 滚轮、Shift 横向平移、缩放上下限与只读保护。其余用例同时覆盖该文件中的既有画布编辑及保存行为。

TypeScript 检查、Vite 构建及改动检查通过。测试运行于虚拟机内的 jsdom 环境，不等同于真实 WebView 鼠标验收。主程序及安装器已重新编译，文件版本与程序集版本均为 0.1.37.0；26 个数据兼容性锁定文件通过检查。
