# Nook · 0.1.35 预览版

图片优先的新看图布局、窗口内专注模式、无边框缩略图和按需翻页箭头。首页围绕素材浏览重新排布；图库提供更易拖动的滚动条与回顶部，截图支持连续绘制和三种箭头。

## 安装和更新

1. 下载 `Nook-Setup.exe`。已有 Nook 时，先保存编辑内容并从「更多 → 退出 Nook」正常退出；右上角 × 可能只是收进托盘。
2. 安装后使用桌面或开始菜单中的 Nook。安装器保留图库、设置、贴图、画布及已经选择的保存路径，不把 D 盘图库重新变成 C 盘空图库。
3. 后续可在「设置 → 关于与更新」主动检查；本版为预览版，需要允许预览版本。先保存编辑内容，再点「下载并重启更新」；下载和校验完成后会准备备份并正常退出更新，准备阶段可以取消。

更新采用固定启动入口，内部先准备并验证新程序，正常保存退出后切换。新主窗口确认启动成功后，清理已核对身份的旧程序文件；不因同名目录就删除内容。失败时保留旧程序及恢复入口。旧目录混有素材、未知文件、正在使用的程序或校验不符时会保留并提示，不承诺删除所有历史文件。备份不等于完整素材副本。

安装版主图库窗口和新快捷方式统一到固定启动入口 `Launcher\Mori.exe`。**已有任务栏固定项不会自动改写**：若它指向历史版本目录，需要取消固定后重新固定一次。旧受管理入口的转交兼容不能保证任意更早固定项都有效；实际任务栏固定 / 取消固定尚未完成本轮验收。

便携包为 `Nook-0.1.35.0-portable.zip`，完整解压后运行 `Mori.exe`。兼容文件名沿用 Mori，不是另一套软件；不要只复制单个 EXE。便携版采用手动更新，不注册 Windows 图标组件。安装器拒绝降级或用不同内容覆盖相同版本。

环境：Windows 10/11 x64、.NET Framework 4.8；画布、3D 和部分视频使用 WebView2，OCR 组件可能需要 Visual C++ x64 运行库和相应语言包。安装包尚未商业代码签名。

## 日常使用

- **素材库**：拖入图片或文件，分类、搜索、多选整理；本地快捷收藏保留原文件地址。文件夹快捷方式留在本地收藏，避免当成图片素材混入全部素材。
- **图片和文件预览**：打开图片、视频、PDF、文本及支持的设计文件。图片右键可复制、钉在桌面；PDF / AI 采用紧凑工具栏、页码跳转和可收起的页面缩略图，保留连续滚动与中键拖动。F11 在当前窗口内隐藏工具，Esc 先恢复工具、再关闭；PSD/AI 的可见内容取决于原文件是否包含可用预览或 PDF 兼容数据。
- **项目画布**：左侧「项目」浏览画板缩略图。选中图片后「加入画布…」明确选择新建或已有项目；支持移动、缩放、绘图、文字、置顶和隐藏工具。
- **截图和翻译**：选区边缘可直接调整，旧标注可以重新编辑；截图功能在设置中选配。右侧钉图图标位于取消、完成之前。贴图悬停无工具栏，右键调整；拖动移动、滚轮缩放、Ctrl+滚轮透明度仍可用。长截图在选区旁预览，只有编辑才打开编辑窗口。
- **格式转换**：素材右键「转为」后点目标格式；生成独立副本，保留原件。外部文件可拖到「工具箱 → 格式转换」。额外引擎在设置中按需安装、更新和卸载，不保证任意格式互转。

## 浏览器收藏

「设置 → 浏览器收藏 → 安装 / 修复」准备固定插件目录，再按页内首次安装说明在 Chrome / Edge 确认加载。已有插件可以在同页一键更新；插件等待正在进行的收藏、编辑和弹窗结束后重载，以新版本实际连接回执为准。

0.2.28 修正重复收藏复用原件时的分类提示，不再把未知原分类误报为“未分类”。本次虚拟机升级期间保持测试 Chrome 打开，升级后插件继续连接并完成生成 PNG 图片的右键收藏，无需重启浏览器或手动重载插件。真实跨窗口拖拽、复杂网站的全部图片类型仍未全面验收。

换电脑需要重新配对，不复制旧电脑的密钥。插件随安装包提供，不在线下载远程执行代码。收藏结果不确定时保留状态，避免自动重发造成重复。

## 本版修复和验证边界

本版整理首页、类型筛选恢复、缩略图缓存与隐藏图库加载，修复取消存储迁移后预览恢复；新增主窗口任务栏固定标识，调整贴图右键和截图钉图位置。Windows 内容缩略图、SVG 预览和格式图标沿用 0.1.33 的范围，见 [文件预览说明](modules/shell-preview/README.md)。

2026-10-29 的多个 0.1.33 开发构建在隔离虚拟机完成首页、缩略图、任务栏属性、安装保护、贴图及截图检查；浏览器使用无界面 Edge 和模拟通信。它们不是 0.1.34 完整包验收。上一已发布 0.1.33 的实际升级与文件缩略图范围见 [历史验证记录](docs/Nook0.1.33验证记录.md)。

PDF 连续预览已改为受限子进程渲染，发布包内的精确程序通过 310 项 PDF / AI 专项检查，测试进程正常退出。完整安装后确认新主窗口和固定入口，旧 0.1.34 程序目录自动清理。**待完善范围：** WEBM 缩略图、密集小字 OCR、复杂网站拖拽、画布排序与分类搜索；GitHub 自动更新全流程、多显示器和长期资源趋势未全面验收。不保证所有格式或所有电脑均可用。

为保持已测安装包和 ZIP 字节不变，包内文档保留封包时的候选状态。发布页独立的 `Nook-Guide.txt`、本仓库说明和验证记录提供更新后的步骤与结果。

## 数据迁移

安装包不含你的素材。换电脑时先在旧电脑导出图库，新电脑恢复并选择图库；本地快捷收藏的原文件、贴图和完整画布目录需要分别迁移。新电脑已有内容时不要直接覆盖。详见 [使用说明的换机步骤](docs/使用说明.md)。

## 构建和许可

`build.ps1` 编译桌面程序；`-Test` 会运行程序测试，请在隔离测试环境使用。`package.ps1` 要求通过数据兼容性校验、带对应源码的滚动截图组件，以及已冻结验证的启动器；普通发布复用 `dependencies/update-launcher-v1`，不每次重建启动器。源文件使用固定 LF 换行，以免 Windows 检出改变兼容性校验值。

测试与开发用的数据、截图、配对文件、密钥及个人素材不属于发布内容。发布包提供 `SHA256SUMS.txt`，GitHub 更新还校验安装器身份和版本。
