Nook 0.1.33 预览版 · 文件缩略图与格式图标
主程序/安装器：0.1.33.0；浏览器插件：0.2.27。
发布标签：v0.1.33-preview

本次变化
1. Windows 桌面和资源管理器继续优先显示系统已有的图片、视频和文档内容缩略图。
2. 新增 SVG 内容缩略图。正常安装并启动后自动注册，退出 Nook 后仍可由资源管理器使用，不需要保持看图窗口打开。
3. 由 Nook 默认打开的文件在无法生成缩略图时，显示带格式标记的文件图标；小图标使用类别符号。其他默认应用保留原图标，Nook 程序、快捷方式及“打开方式”的应用标志不变。
4. 保留用户默认打开方式、其他软件已有的专用预览处理器和 Windows“始终显示图标”偏好。便携版、隔离测试窗口不注册系统组件。
5. 图标组件使用独立固定目录，避免资源管理器占用组件后阻止旧主程序清理。沿用固定启动入口、数据路径保护、浏览器连接和旧版安全清理功能。
6. 安装业务版本直接读取编译元数据，并在打包时核对，避免版本常量漏改造成错误的同版本判断；同版冲突和降级保护继续保留。

- 最终安装后的 11 项 Shell 检查取得 SVG、PNG、MP4 的真实内容像素，并在资源管理器查看，未把图标回退算成缩略图成功。
- 18 项安装保留检查通过；测试图库字节、计数、素材、分类、设置、保存路径、贴图、画布、浏览器文件和快捷方式保留。核对的 88 条 UserChoice 观测及原有系统/第三方处理器未被意外修改，旧 0.1.32 主程序由正常流程清理。
- 0.1.33 安装器版本与安全检查 319 项、通用图片处理器回归 22 项通过。
- 前置原生组件 59 项、注册与回滚 122 项、Shell 定向 10 项检查保留原版本身份；没有声称后续修复重跑了全部旧测试，也不把各组相加为独立功能总数。93 个 ICO 和原始许可文本完成字节校验。

已知边界
- 本版没有新增所有视频编码、PDF、PSD、AI 的通用资源管理器缩略图解码器，已有预览能力继续依赖系统及已安装组件。
- 包含外部资源、脚本、内嵌位图、动画或超出处理预算的 SVG 回退到图标，不改变原文件。文字 SVG 首次字体扫描可能较慢。
- Windows 原生 MP4 首次缩略图请求出现过偶发失败，此现象在 Nook 注册前基线也出现；资源管理器及后续独立复测取得真实画面。保留失败记录，不保证所有首次请求均成功。
- WEBM 缩略图、真实跨窗口拖拽、密集小字 OCR、复杂网站、混合 DPI 多屏、长期性能与完整 GitHub 自动更新交接尚未全面验收。
- 已知画布仅打开关闭可能改变排序，分类搜索入口仍可优化。
- 旧目录混有个人文件、未知文件或仍被占用时会保留并提示，不按名字无条件删除。安装包未商业代码签名。

下载与安装
发布页：https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.33-preview
通常下载 Nook-Setup.exe；保存编辑信息并从“更多 → 退出 Nook”正常退出旧版后运行。已有更早版本可直接升级，无需逐个安装中间候选。安装保留现有图库和路径，新主窗口确认健康后清理已核对的旧程序。
便携版完整解压 Nook-0.1.33.0-portable.zip 后运行 Mori.exe；它不注册本次 Windows 文件图标和 SVG 缩略图组件。
浏览器插件在“设置 → 浏览器收藏”检查实际连接版本，需要时一键更新；首次安装仍由浏览器确认，不复制别台电脑的配对密钥。
