## 简短选区的验收方式

在专用 Windows 测试桌面打开一行文字，用 Nook 的屏幕采集入口拍取所在显示器，框出文字并触发真实的「翻译」按钮。单独进程内的首张图片、同一进程内的另一张新图和重复图片分别统计。「首帧」要求截图区域已经贴上译文，或在区域旁已能读到返回的译文。仅出现复制入口、等待提示、后台文字或尚未排进去的译文均不能计时为成功。

使用含正式 OCR 组件的测试目录，每种场景分别启动一次。测试仅使用夹具提供的文字。在线场景使用默认腾讯服务。

```powershell
.\QingJie.Tests.exe --live-capture-translation-timing menu
.\QingJie.Tests.exe --live-capture-translation-timing sentence
.\QingJie.Tests.exe --live-capture-translation-timing dark
.\QingJie.Tests.exe --live-capture-translation-timing grey
```

每次只在屏幕中检测到本次随机边框后才发送框内文字。逐项核对 `OCR`、`result` 和 `first_readable_ms`；若错误、无法显示或超过 2000 毫秒，该项返回失败。执行器能启动程序与此项验收通过是两件事。
