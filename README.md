# Mori Desk · 0.1.12 预览版

Windows 10/11 x64 的本地工具集合。单个安装包，统一素材窗口和托盘；3D 与独立看图按需启动，OCR 使用短期工作进程。

## 在另一台电脑安装

1. 在浏览器登录有权限的 GitHub 账号，打开 [0.1.12 下载页面](https://github.com/lta24131-hub/mori-desk/releases/tag/v0.1.12-preview)。仓库为私有，未登录或账号无权限时可能显示 404。
2. 展开 **Assets**，下载 `Mori-Desk-Setup.exe`。不要下载下面的 `Source code`，那是开发用的源码。
3. 双击安装，完成后打开桌面上的 **Mori Desk**。本版使用独立数据，不覆盖旧 Mori / Luma。
4. 首次测试建议先用右上角 **工具**，依次打开图片、3D 模型、输入翻译和截图。
5. 需要网页拖拽收藏时，再按照 [详细使用说明](docs/使用说明.md) 的“连接浏览器插件”操作。

安装包约 13 MiB，程序文件约 32 MiB，不含系统运行时、个人图库、缓存及可选语言包。Windows 10/11 **x64**；不适用于 macOS。本版为未签名预览版，主程序没有自动更新或完整卸载器；浏览器插件可在设置中更新。

## 开始使用

双击 `Mori-Desk-Setup.exe` 安装；或完整解压便携包，运行 `Mori.exe`。不要单独复制 EXE。无需管理员权限。3D / 部分视频依赖系统 WebView2 运行时，基础截图识别依赖 Windows 中文或英文 OCR 组件。

- **素材库**：全部素材汇总图片、动图、视频、音频和模型，含符合类型的本地快捷收藏；网址和文档有独立入口。点“导入素材”、网页收藏和图片粘贴保存副本；普通电脑文件拖入默认只记位置。右侧最下面显示本地地址及保存方式。保留分类、撤销、批量操作等功能。
- **本地收藏**：拖入任意文件 / 文件夹，仅记录路径；文件夹内容不递归导入。大文件夹与小文件图块分开，空白处右键可新建分类文件夹；拖入分类只整理快捷收藏，不移动原件。Ctrl/Shift 多选，Delete 移除收藏，Ctrl+Z 撤销。移除收藏不删除原件，解散分类保留内容。原件改名、移动或换电脑后仍依赖原路径；F5 可刷新。搜索、排序、筛选复用已加载元数据，编辑信息时暂缓刷新保护草稿。
- **工具 → 截图**：复用 Luma 截图、标注、原位翻译、OCR 文字选择、贴图与恢复；工具条新增“收藏到素材库”。
- **工具 → 输入翻译**：保留腾讯 / Google / 可选离线中英包、语言包管理。在线翻译发送文字到所选服务，不应输入保密内容。
- **工具 → 打开图片**：不自动收藏；滚轮缩放，拖动查看，左右键切换同文件夹图片，双击或 Esc 关闭。GIF 可播放，SVG 使用隔离渲染。
- **工具 → 打开 3D 模型**：STEP/STP、STL、OBJ、GLB、3MF。本地加载，旋转、缩放、材质、结构线、坐标方向、全屏。大模型仍受机器内存和 STEP 解析复杂度影响，不保证秒开。

主窗口关闭后收进托盘；托盘“退出 Mori Desk”完全退出主程序，未完成的截图退出前询问。已独立打开的看图 / 3D 窗口由各自的关闭按钮退出，不随主窗口的隐藏而消失。只看图不需要图库在前台。同时打开不同图库时，只有一个主窗口拥有截图快捷键和贴图；该窗口完全退出后，另一个窗口自动接管，避免重复恢复和写入贴图。

## 文件与安全

- 新版默认数据：`%LOCALAPPDATA%\MoriDesk`。默认图库在其中的 `Library`，可在设置中更改/整体迁移。
- 贴图、翻译设置和可选语言包在新版的数据目录内，**不读写旧 Mori 或 Luma 的数据**。
- 本地收藏保存在当前图库数据库中；图库备份含这些引用，**不包含引用的原件**。换电脑时必须另行迁移原件，保证相应路径可用。
- 撤销保留当前会话最近 30 步，使用有容量上限的元数据差异记录；不存图像 / 模型副本，重启后不会保留撤销历史。
- 本版没有自动迁移旧软件、卸载旧版、自动云同步、主程序自动更新或默认文件关联。安装包未进行商业代码签名。
- 旧 Luma 正在运行时可能占用 F1 / F3 / Ctrl+Alt+T；请先通过工具菜单体验，确定替换后再统一快捷键。

## 浏览器收藏插件

保留拖拽、右键收藏和浏览器书签导入，使用独立本机连接 `app.mori.desk`，不覆盖旧 Mori。

1. **设置 → 浏览器收藏 → 安装 / 修复**，再展开首次安装说明。新安装使用固定目录和固定身份，不需要手动输入 ID。
2. 首次在 Chrome / Edge 扩展管理页确认加载；旧插件第一次升级仍需重新加载一次。原插件身份及偏好设置会保留。
3. 之后安装新版 Mori，在同一设置页点 **一键更新**。插件等待收藏和编辑结束、弹窗关闭后安全重载；收到新版本确认才显示完成。

更新仅来自随 Mori 安装的插件文件；无远程代码下载。更新控制不访问或初始化图库。多个浏览器同时使用同一插件目录时暂缓更新；保存结果不确定时，需要用户先核对，不会自动重发收藏请求。

浏览器本身要求确认安装扩展，所以换电脑后此步骤仍需手动执行。未授权前本程序不会修改你的浏览器。

## 本轮改进

修复未保存备注时从托盘恢复出现空列表、分类撤销覆盖无关改动和本地分类目标失效的问题。图片预览后台加载，关闭取消排队，隐藏时暂停 GIF；3D 换图取消前一份原始读取。插件 0.2.18 改善慢收藏与连接中断时的提示，不自动重发未确认的保存；设置支持 Esc 退出。本轮主要提高响应与一致性，不声称总解码耗时或常驻内存一定下降。完整累计更新见版本说明。

换电脑后首次安装插件仍需浏览器人工确认；现有电脑更新时先备份、保存编辑内容并通过“退出 Mori Desk”完全退出，再运行新安装包。安装完成后，在“设置 → 浏览器收藏”中更新插件；曾开启自启动的用户需重新勾选并保存自启动选项。不要覆盖旧电脑的浏览器配对文件。

[本轮测试与体验检查](docs/体验检查.md) 记录验证结果和剩余限制，不要求你先承担测试。

## 开发与测试

`build.ps1 -Test` 编译并运行本地收藏、安全及路由测试。
`Mori.exe --self-test <新的测试目录>` 运行原素材库回归检查。
`Mori.exe --integration-test` 使用合成英文图片验证 OCR 子进程、腾讯双向翻译及原位渲染，产生测试报告（需联网）。
`Mori.exe --ui-test <测试图库>` 打开隔离窗口，不注册全局快捷键或托盘。
`package.ps1` 生成有文件白名单的便携 ZIP 和单文件安装器，不包含个人素材、设置、截图、贴图或 API 密钥。

桌面源码来自 Mori、Luma 的独立副本，3D 网页部分以预构建的离线资源包含在 `web/model` 中；构建桌面程序不需要重新构建该网页。原项目保持不动，第三方许可随包附带。
